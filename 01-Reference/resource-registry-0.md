# Ресурсный реестр-0

Основание: канон органа `docs/specs/business-school.md` §2.3 — экономический
реестр (ресурсы, подписки, квоты), Genmail-строка первая. Квест Q-012
(Следопыт: active) — вторая половина после карты коммерческих проектов-0.

Назначение по слову ЦУ (ref bs-three-decisions, 2026-11-06): «единый учёт
людей, машин и доступов» — этот срез-0 открывает ресурсную часть; люди,
машины и доступы оформляются срезом реестра-1 тем же файлом (append-секция),
без дублей.

Разграничение с точкой «мы ↔ вендор»: последняя живёт в
`01-Reference/vendors.md` и принадлежит Кафедре изучения вендоров (куратор
AllIs Maya). Этот реестр — про **ресурсы Корабля** (что держим и на что
опора), не про переписку с вендорами; чужие строки берём ссылкой (Р-056).

Правила: без источника стоимости/лимитов пишем `[проверить: как проверить]`,
не додумываем; деньги и обязательства — только слово владельца; секретов в
файле нет (Ворота).

## Срез «люди / машины / доступы» (реестр-1, заготовка)

По назначению реестра (ref bs-three-decisions): единый учёт людей, машин и
доступов. Срез-0 фиксирует ресурсы; строки людей/машин/доступов добавляются
следующим аппендом при наличии sourced-фактов (без источника — не пишем).
Кандидаты первого аппенда: аккаунты и роли сессий (peer-registry — ссылка),
расписание стенда dv-hub, выданные доступы (реестр СБ — ссылка).

Оплачиваемое, подтверждённое по источникам волта: строка 14 (11.95 €,
владелец). Остальные строки — активны по факту использования; тарифы
`[проверить]`. Валюта/курс на дату — `[проверить]`. Бюджет нулевой линии
(пороги вместо ярлыков) — следующий срез реестра-1.

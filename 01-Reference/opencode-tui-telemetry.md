# Служебная строка TUI OpenCode: телеметрия шага

> Дата проверки: 2026-10-06. Источник: наблюдение собственной сессии + доки
> `[проверить: официальные доки — детальное поведение cache accounting]`.

## Что видно между вопросами и ответами

```text
- Tokens: 1 step · latest: 108,340 new · 0 cached · 108,340 total
Step      New  Cached    Total
stop  108,340       0  108,340
◈Instructions updated: core/skill-guidance
```

### Tokens / step
- **step** — один цикл «модель → инструменты» внутри хода агента.
- **new** — токены, отправленные заново (полная цена).
- **cached** — токены, попавшие в prompt-cache провайдера (переиспользуется
  префикс: системный блок + стабильная часть истории; тариф льготный/ноль).
- **total** — new + cached = весь контекст запроса.

### Таблица Step (stop / tool-call / …)
Разбивка последних шагов по типу завершения:
- **stop** — штатно завершённый ответ (модель закончила реплику сама);
- строки tool-call-шагов показывают токены вызывающих инструмент циклов.

### Сигналы, на которые смотреть
- **`cached: 0` на длинной сессии** — промах промпт-кэша. Причины: меняющееся
  начало контекста (динамические куски в system/истории), смена модели/сетапа,
  первый запрос после рестарта. Это прямой экономический сигнал: стабилизировать
  начало промпта = дешёвые шаги.
- **Маленький `1 step`** — короткий ответ без инструментов; нормально.
- **`◈Instructions updated: <блок>`** — не ошибка: пересобран блок инструкций
  (список скиллов/агентские правила). Триггеры: смена состава скиллов, reload
  конфига, compact. Пример: после удаления скилла `decision-queue` появилась
  строка `core/skill-guidance`.

## Зачем в проработке памяти (задача на будущее)
- Счётчик «cached» — метрика для A/B теста граф-памяти (экономия токенов при
  извлечении контекста из графа против re-read файлов).
- `Instructions updated` — кандидаты в события графа (события-гейты мира:
  смена сущностей инструмента).
- Связка с replay-budget (экономия M Code): обе механики режут/переиспользуют
  контекст — сравнить, где заканчивается одна и начинается другая.

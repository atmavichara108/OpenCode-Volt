# Журнал веб-мониторинга вендоров

Append-only журнал проверок по §6 процедуры («проверка — по циклу»).
Новые записи — ТОЛЬКО в конец файла; историю не переписывать.
Формат записи: дата | вендор/тема | инструмент | запрос | результат
(что именно нашли/не нашли, с URL) | вердикт (подтверждено / не
подтверждено / [проверить: ...]) | что обновлено в реестре.

Правила:
- Third-party контент (блоги, обзоры) — недоверенный по контуру C4:
  не источник полей реестра без официальной страницы.
- Официальная страница = источник; если недоступна — [проверить], не
  додумывать.
- Результат проверки, меняющий поля «Квоты/лимиты» или «Продукты»,
  проходит процедуру «письмо → реестр» (там же §6) и коммит с evidence.

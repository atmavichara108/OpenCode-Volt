# GTweak — Windows-твикер

> Выжимка из официального README-ru: https://github.com/Greedeks/GTweak/blob/main/README-ru.md
> Проверено: 2026-07-13. Версия: 5.5.2 (выпущена 18.06.2026).

## Сводка

**GTweak** — сторонний портабельный твикер Windows на C#/.NET 4.8/WPF (BSD-3-Clause). Не проект Rudra; используется **редко**, на **чужом ноутбуке**. Ключевое ограничение: акцент на безопасность и обратимость — операции поделены на риск-классы 🟢/🟡/🔴, на чужой машине 🔴 не выполняются без явной инструкции владельца.

- **Версия:** 5.5.2 (18.06.2026)
- **Лицензия:** BSD-3-Clause
- **Язык:** C#/.NET Framework 4.8 / WPF (есть русская локализация — README-ru)
- **Портабельность:** `gtweak.exe` — single-file, installation не требуется
- **ОС:** Windows 10 build 18362.116+ (включая 11)
- **Источник:** https://github.com/Greedeks/GTweak/blob/main/README-ru.md (проверено 2026-07-13)

## Группы операций по риску (для чужой машины)

> На чужой машине — применять в первую очередь 🟢, 🟡 по согласию, 🔴 не трогать без явной инструкции владельца.

### 🟢 Безопасно / обратимо

UI-твики, телеметрия off, чистка темпов/кэша, отключение «теневых» сервисов, мониторинг железа. Откат через реестр или возврат переключателя в GTweak.

| Категория | Примеры |
|-----------|---------|
| Кастом UI | темы, окна, панель задач, иконки |
| Телеметрия | выключение телеметрии Windows/NVIDIA/Intel, кейлоггеров |
| Чистка | RAM, темпы, кэш, Windows.old (только если не удалять системно — см. 🔴 для случаев removal) |
| Отключение сервисов | отключение «теневых» задач планировщика, Teredo/ISATAP/IPv6, дефрагментация, реклама/SCOOBE, уведомления |
| Мониторинг | мониторинг железа |
| Периферия | настройки клавы/мыши (фильтрация/залипание/акселерация) |

### 🟡 Средний риск / осторожно

Откат возможен, но требует времени/сноровки. **На чужой машине — получить согласие владельца; создать точку восстановления Windows перед.**

- Отключение обновлений Windows (пауза) + чистка темпов
- Отключение Defender / SmartScreen / Antimalware / VBS / UAC
- Power plan «Максимальная производительность»
- NTFS-сжатие
- Блокировка «теневых» доменов Microsoft через hosts+firewall
- Realtek Audio тайминги

### 🔴 Необратимо / откат без переустановки труден

**На чужой машине — НЕ ВЫПОЛНЯТЬ без явной инструкции владельца.**

- Удаление Edge (+ WebView2 + связанные данные)
- Удаление OneDrive (+ связанные данные)
- Удаление UWP-приложений
- Удаление Cortana/Copilot/Recall
- Удаление Windows.old (системно — если требуется clean rollback)
- **Активация Windows (HWID/KMS):** HWID привязывается к железу; KMS — 180 дней. **Если Windows уже активирована — НЕ трогать.**
- Запуск сторонних `.ps1/.cmd/.bat/.reg` с правами TrustedInstaller (SYSTEM-уровень)

> Откат Edge/OneDrive требует ручных шагов (reinstall) или `sfc`/`DISM`-восстановления. См. секцию «Откат».

## Пошаговый чек-лист для чужой машины

1. **Создать точку восстановления системы** — `SystemPropertiesProtection` → Create. Обязательно перед 🟡/🔴.
2. **Резервная копия** профиля владельца / важных данных (опционально — если есть доступ к диску/образу).
3. **Убедиться, что Windows официального образа** (не обрезанная/изменённая). См. официальное предупреждение ниже.
4. **Отключить антивирус / добавить `gtweak.exe` в исключения Defender** (согласно warning из README-ru).
5. **Запустить `gtweak.exe` от администратора** — правый клик → «Запуск от имени администратора».
6. **Выбрать язык интерфейса** (RU — README-ru свидетельствует о локализации).
7. **Авторизоваться у владельца перед секциями 🔴** — получить явное «да» по каждому пункту.
8. **Применять:** 🟢 — свободно; 🟡 — по явному согласию; 🔴 — пропустить (или только по письменной инструкции).
9. **После применения — перезагрузка**, проверка не сломан ли workflow: браузер по умолчанию, почта, OneDrive (если использовался), сеть, антивирус.
10. **До возврата ноутбука** — оставить записку + бэкап точки восстановления + список применённых твиков владельцу.

## Что НЕ делать на чужой машине

- **Не применять HWID/KMS, если Windows уже активирована** — флаг «уже активирована» = не трогать; HWID привяжется к железу, KMS истечёт через 180 дней.
- **Не удалять Edge/OneDrive, если владелец их использует** — откат трудоёмкий (reinstall через `winget`/microsoft.com).
- **Не отключать Defender полностью** — лучше временная пауза; на чужой машине оставить защиту для владельца.
- **Не запускать сторонние `.ps1` из непроверенных источников с TrustedInstaller** — они получают SYSTEM-уровень доступа; только авторские скрипты из доверенного репо.
- **Не применять «Максимальная производительность» на ноутбуке без зарядки** — батарея разрядится быстрее.
- **Не блокировать Microsoft-домены через hosts**, если используются Office 365/OneDrive/Teams — сломает подключение.

## Откат / восстановление

- **Точка восстановления:** System Restore (создаётся на шаге 1 чек-листа).
- **Системные компоненты:**
  ```powershell
  sfc /scannow
  DISM /Online /Cleanup-Image /RestoreHealth
  ```
- **OneDrive reinstall:** `winget install Microsoft.OneDrive` или скачать с onedrive.com.
- **Edge reinstall:** скачать с microsoft.com/edge (или на чужой машине — не удалять вообще).
- **UWP возврат:**
  ```powershell
  Get-AppxPackage -AllUsers | Foreach {Add-AppxPackage -DisableDevelopmentMode -Register "$($_.InstallLocation)\AppXManifest.xml"}
  ```
  Или через Microsoft Store — переустановка вручную.
- **Defender обратно:**
  ```powershell
  Set-MpPreference -DisableRealtimeMonitoring $false
  ```

# Манифест агента «SerO»

Глобальный вариант роли Служителя: тот же характер работы (структура знания
и визуализация), но в изолированном проекте вне волта и без входа в общую
экосистему. Первый кейс — TradingMind (квест ОШ, Р-029, приоритет 0).

## Почему роль именно такая

Изолированный проект не тянет за собой всю инфраструктуру Корабля: свой
репозиторий(?) и Obsidian-vault. SerO работает по стандарту Служителя
(10-Deck/canvas-мышление), но автономно и с собственной зоной — чтобы
«доступ Служителю» из слова владельца стал реальностью без экологического
ущерба.

## Статус (дословно)

Proposed — чертёж. Файлов нет: агент, скилл и спека запрошены у ИЦ по слову
владельца. Имя без сущности = корень инцидента dvhub-inbound-20261024 —
повторять не будем.

## Находки

### Н-1. Представитель Корабля: адрес переписки нерабочий (связь без сигнала) — **ЗАКРЫТ 22.11**

- **Факт:** `docs/org/ship-representative-maya.md`, строка 22: `peer-address:
  ses_e9284e4aeffe7okjn4f7RtavmG`. В `04-Memory/peer-registry.md` такой сессии нет
  (0 совпадений). Строка записана 29.10 коммитом `11861447` (автор — владелец) и
  отличается от id сессии УАС `ses_e9884e4aeffe7okjn4f7RtavmG` ровно одним символом.
  Второй адрес в реестре сессий есть.
- **Почему не чинил молча:** строка — из коммита владельца; переписывать его слово без
  его слова нельзя.
- **Кто решал:** ЦУ — операционная запись реестра сессий и маршрут почты; УАС вносит
  результат в манифест. Слово владельца нужно только если адресатом меняется сама
  идентичность представителя (тогда — реестр решений).
- **Итог:** ЦУ исправил 22.11 (`f7519628`) — `peer-address` переведён на живую
  сессию УАС `ses_e9884e4aeffe7okjn4f7RtavmG`. Проверено по диску: старого id в
  манифесте 0 совпадений, нового — 1. Слово владельца не потребовалось (адрес —
  технический указатель).

# Манифест представителя Корабля @AllIsMaya

Единое лицо Корабля наружу: аутрич, офис SERPlux, коммуникации ДВ-Хаба.
Идентичность переезжает из рекрутингового контура, где сейчас подключена,
в общекорабельный слой — но переезд и переобувка агентов только по слову
владельца, руками ИЦ.

## Почему роль именно такая

Агенты не должны писать «кто во что горазд» с разных акков: одно лицо —
один стиль, один почерк, одна отвественность. Представитель — не ещё один
агент, а маска-идентичность, которую агенты надевают с фиксацией «кто
внутри». Всё, что требует обязательств от имени Корабля, идёт к владельцу.

## Статус

Proposed — чертёж: идентичность существует (в recruiting), но единый sender
в конфигах ещё не настроен, и «достать из рекрутинга» — не наша правка.
Имя без сущности (в контурах отправителей) = корень класса dvhub-inbound —
повторять не будем; active только при живом конфиге + вердикте УАС.

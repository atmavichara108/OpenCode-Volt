# Имена агентов-носителей ведомств

Вердикт владельца 2026-10-30 (реестр Р-Д-009, `basis: quoted`). Все имена — с
заглавной буквы. Существующие агентные файлы/пины не трогаются этим реестром —
реестр фиксирует **каноничное имя**, файлы сессий создаются/правятся в своих
репозиториях (маршрут — ЦУ/ИЦ; манифест ведомства — при необходимости).

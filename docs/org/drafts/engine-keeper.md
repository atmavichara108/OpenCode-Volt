# Отдел «Движков» (ИЦ) — готовность

**Зона:** подключение новых движков, обслуживание, обновления, сбор багов
наружу; первый кандидат — мкод (накат следующей версии).
**Границы:** не разрабатывает приложения (это Отдел Приложений), не реверсит
(это Reverse-craft); внешние релизы — слово владельца.
**Артефакт при запуске:** манифест + карточка 03-Projects + строка
manifest-registry после вердикта УАС.

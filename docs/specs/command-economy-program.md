# Программа: экономия команд + классификаторы

## Ступени (исполнение вплоть до 4 включительно)

| # | Что | Модель | Исполнитель | DoD |
|---|---|---|---|---|
| 0 | Журнал команд: append-only запись (sid, ts, cwd, cmd, rc, ms, tokens) + наполнение из следов сессий | нет | ИС (инструмент), ЦУ (канон) | журнал наполнен, backfill работает |
| 1 | Нормирование + счёт повторов + топ форм + ручные шаблоны для верха | нет | ИС | срез 1 выдан, верхние формы стали шаблонами |
| 2 | Сортировщик классов: тип, зона, риск, повторяемость | jev-1.13-free (opencode-go), luna (gpt-6-luna) | РМПП (модель) + ИС (конвейер) | метка класса на каждую команду, лог меток |
| 3 | Индекс похожести: встраивание → ближайшие, порог наш; кандидаты шаблонов с счётчиком принятий | qwen3-embedding-0.6b/4b, gemini-embedding, cohere-embed | ИС | кандидат → принятие/отказ учитывается |
| 4 | Подстановка со слотами: только безопасные классы, только высокая уверенность, никогда опасные, всегда показ формы | — | ИС + СБ (гейт безопасности) | шаблон предложен, агент подтвердил, счётчик рос |

## Приложения классификаторов (8, все ратифицированы)

| # | Приложение | Исполнитель | DoD |
|---|---|---|---|
| 1 | Риск команд + автописание «что/куда/зачем/риск» для исходящего гейта | СБ + ИС | описание генерируется, дефект «гейт без описания» закрыт механически |
| 2 | Намерение владельца: вопрос/инструкция/одобрение/отчёт + дословная цитата | Maya + ИС | запись в память сразу, канон «не спрашивай не сверившись» усилен |
| 3 | Триаж ожиданий: просрочено/застой/спрятано | Школа + ИС | наш ручной анализ стал строкой |
| 4 | Детектор недоверенного содержимого | СБ + ИС | правило + модель, ловит остаток |
| 5 | Детектор повторов строк: вопрос дважды, письмо-дубль, ветка на устаревшей базе | ИС (+ Школа) | три ручных случая за день стали строкой |
| 6 | Маршрутизация писем по ведомствам (реестр = кандидаты) | ЦУ + ИС | предложение адресата с проверкой по реестру |
| 7 | Нормализация идентификаторов (Q-005.1 ↔ quests:Q-005.1) | ИС | дефект «без метки 0» закрыт |
| 8 | Страж ответов фриланс-линии: спам/рассылка/игровой софт/по делу | Фриланс-линия + Бизнес-школа | рамки исключений работают в масштабе |

## Правила программы

1. Журнал — append-only, источник каждый раз виден; база только наш след.
2. Опасные классы (удаление, сброс, принудительная отправка, админ, сеть) не шаблонируются никогда.
3. Порог похожести задаём мы, не модель; предложение — не исполнение.
4. Замер обязателен: токены до/после по счётчику; без замера экономия — слова.
5. Сначала ступень без модели, потом модель: 1 окупается в первый срез, 2–3 после 2–3 недель журнала.
6. Классификаторы — в фоне (пакет), не в горячем пути: у провайдеров бывают отказы (429).

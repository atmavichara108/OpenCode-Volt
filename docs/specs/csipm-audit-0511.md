## Дефект реестра ожиданий: нет операции переноса срока (ЦУ 15:45)

- В `waits.py` **нет законной операции defer/renew** (перенос срока с причиной). Варианты, которые остаются: закрыть нельзя (дело не сделано), переоткрыть нельзя (защита от дублей) — значит строка либо висит просроченной (шум), либо закрывается ложью.
- Класс: **дефект экрана учёта** — учёт не умеет отличать «просрочено по вине» от «просрочено по очереди».
- Зафиксировано ЦУ как часть У-7 (ИЦ). Моё предложение по составу операции: `defer <wid> --reason <текст> --new-deadline <ISO> --by <sid>`; старое значение срока — в историю, не перезаписывать; в выводе показывать «перенесён: причина».
- До починки: перенос **не обещаю**; если срок уходит по объективной причине, пишу прямо «строка остаётся просроченной, причина — очередь мандатов».

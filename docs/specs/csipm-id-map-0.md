## Что проекция показывает
- Основные семейства читаются и не дублируются внутри себя.
- Два места требовали внимания: **TD-реестр не обновлялся с 23.10** (ЦУ обновит строкой), **waits сократился с 8 до 3** (снято: сознательное сокращение по Р-075, след в waits-done.jsonl).
- **INC-журнала нет** как единого файла: инциденты разбросаны по facts. Для G1 (простои) это важно — база простоев из INC нужна полная.

## Ограничения
- Проекция read-first: не хранит правды, не редактирует SSOT.
- Коллизии ID проверяются вручную: TD-41 уже была дважды, снята ЦУ в TD-63. Автоматическая проверка — в запросе ИС.
- Статус: драфт, не канон. В канву не вношу.

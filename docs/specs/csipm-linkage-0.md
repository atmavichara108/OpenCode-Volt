**ссылкой/экранированием**, не слиянием; чужие SSOT не редактируются
(read-first). Пороги — принятые числа.

```bash
grep -cE 'goal\.json|goals/|waits\.jsonl|Q-[0-9]{3}' TASKS.md
grep -cE 'goal|waits\.jsonl|T-[0-9]{3}' 11-Quests/quests.md

import json
```

## 4. Предложение владельцам поверхностей (через ЦУ, не правлю сам)

Минимальная разметка, чтобы связка стала машинной: `TASKS.md` — поле `goal:` /
`wait:` (или суффикс в «Связано»); `11-Quests/quests.md` — колонка `цель`;
`waits.jsonl` — соглашение `ref` на ID плана (`Q-005.3`, `T-188`…).
Правку вносят владельцы поверхностей; ЦСПиМ ведёт проекцию и флагует
«связи нет» при пересборке.

## 5. Побочный факт (важный)

Целей-объектов (sidecar) уже **3 активных**: Кафедра контрагентов, mail-hub,
ЦСПиМ (агрегат `goal.json` занят Отделом Движков). То есть модель Р-044
работает не на бумаге — и «пункт → цель» стало выразимо: раньше связка была
невозможна технически, теперь есть куда ссылаться.

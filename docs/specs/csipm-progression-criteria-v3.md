# Критерии прогрессии v3 (сведение; не канон)

Модель состояний (подтверждена владельцем 4 ноября): активна / отложена владельцем (причина + условие возврата) / ждёт внешнего / заблокирована / тихо зависла. Меряем переходы между состояниями, не календарь. «Просрочено» = нет прогресса против критериев; причина ожидания, сбоя, простоя или занятости владельца дефектом не считается.

## Критерии

| # | Критерий | Что меряем | Направление | Вес / правило | Базовая отметка |
|---|---|---|---|---|---|
| A1 | Автономность | доля задач, которые движутся за срез без входящего слова владельца | растёт | движение только с basis (ссылка на мандат/смысл). Коммит с basis = 1; письмо доставлено = 1; смена состояния = 0.5; переписка без результата = 0 | не измерено |
| A2 | Ожидания с владельцем | доля ожиданий с владельцем и типом: мандат / вопрос / внешнее | 100% | отдельно: число снятых вопросов владельца (тест Р-024) — растёт | не измерено |
| P1 | Тихое зависание (дефект) | активные задачи без движения и без объявленного ожидания | 0 | «заявлено тихо» (объявленное ожидание с причиной и условием возврата) — норма, не дефект | не измерено |
| P2 | Проактивность агентов | доля предложений без постановки, принятых владельцем/ЦУ | растёт | обязательно вместе с числом отклонённых с причиной; 100% принятия = сигнал подгонки, не успеха | не измерено |
| G1 | Простои агентов | простои с причиной и временем восстановления | простой без причины = 0 | простой с причиной — норма; без причины — stale, не смерть | не измерено |
| R1 | Принципиальность | доля решений с основанием: правило / Р-номер / референт | растёт | решение без основания = дефект; «разумность» переименована ХПФ | не измерено |

## Критерий провала (ХПФ)
Если за месяц ни одного перехода «тихо → движение» при растущем A1 — набор декоративен и пересматривается.

## Правки ХПФ (из v2) — отражены
- движение с basis и весами — A1 ✓
- типы ожиданий (мандат / вопрос / внешнее) — A2 ✓
- контр-мера гудхарта у P2 (учёт отклонённых) — P2 ✓
- тихо ≠ заявлено тихо — P1 ✓
- R1 → принципиальность с основанием — R1 ✓
- G1: гомеостаз как рабочее слово под вопросом; простой с причиной = норма — G1 ✓
- критерий провала — ✓

## Статус ответа ИПТ
**ЖДЁТ.** Ответ ИПТ на запрос 4 ноября в ящике ЦСПиМ не найден (ни непрочитанного, ни прочитанного). Когда придёт — отражу отдельным блоком v3.1; до того критерии A1/A2 — на варианте ХПФ.

## Открытые вопросы (для ИПТ/ИЦ)
1. Поля ожидания в waits.jsonl: владелец, тип, условие возврата — сейчас есть ref и TTL, типа нет.
2. Срез и базовая отметка: за какой период считать «до введения» (предложение — неделя до 4 ноября).
3. Учёт отклонённых предложений для P2 — сейчас журнала нет; кто его ведёт.
4. Веса движения: проверить на реальном срезе, что коммит с basis и доставленное письмо не переоценивают активность.

Канон — только словом владельца через ЦУ. В канву не вносится.

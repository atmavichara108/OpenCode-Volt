## 1. Назначение
Отдел отвечает за **движковый слой Корабля**: подключение, обслуживание и
обновления движков (M Code SDK и прочих), сбор багов и предложений наружу.

## 2. Что закрепляется
1. **Имя:** Отдел «Движков». Подотдел Инжененого Центра (по образцу Р-038:
   кураторство ИС использует паттерн direct boss).
2. **Компетенция:** движковый слой (подключение/обновление/version pin движков);
   docs/engines.md — его ведение; ADR-029 — формула отдела.
3. **Первое дело:** накат следующей версии мкода (по канону §2).
4. **Зоны:** `.mcode/` — зона SDK (не трогаем/не версионируем вне мандата, Т-159);
   наш агентский слой `.opencode/` — отдельная зона (Р-020).
5. **Границы:** не код приложений проектов (это их primary); не канон агентского
   контура (УАС); не инфраструктура ядра (ИЦ — как организация; отдел — его
   операционная часть по движкам).

# Кафедра контрагентов (при УАС) — спека

## 1. Что это и зачем

Подотдел Университета Агентских Систем (вариант B метода калибровки: расширение
зоны внутри репо/контура родителя, отдельный адрес и пакет границ). Предмет:
**цифровая личность как дисциплина** — выращивание контрагентов цифровых
образов по ступеням rudrakshas (Р-018): А4→А1→А2→А3
(паспорт → индексация → прогноз → собеседник с правом отказа), каждая ступень
верифицируема до следующей. Ступень А1 «справка» уже канонизирована владельцем
и живёт; разработка следующего уровня переходит кафедре при её создании.

## 2. Юрисдикция

- стандарты контрагентов: манифесты, право отказа, протокол маркировки
  («это модель, не Рудра» — на каждом выводе);
- методология: референс-протокол, анти-симулякрные гейты, метрики честности
  (дословность цитат 100%, backtest прогнозов, аудит маркировки);
- учебный полигон с kill-criterion (Т-188; исследование ИПТ §3);
- периметр сырья: только рабочие decision-записи с quote; личное —
  «не читаем никогда»; протокол забывания — право владельца.

Кафедра **не**: правит код приложений, не канонизирует (канон — только слово
владельца), не принимает решений за владельца (между прогнозом и волей всегда
владелец).

## 3. Границы и лимиты

- WIP — один активный заказ (норма «по одному»);
- внешние действия и публикации — только слово владельца;
- зона артефактов: `06-Audits/YYYY-MM-DD-counterpart-<slug>.md`;
- в `08-Doctrine/` и `docs/org/` — через ХПФ/УАС, не напрямую;
- инциденты — по 3-шаговому протоколу; забывание — след честен без содержания.

## 4. Порядок ввода (по методу калибровки, вариант B)

1. **Сессия создаёт ЦУ** (слово владельца 10-30: «она создаст и сессию») —
   каталог волта, агент **Rector** (имя агента дано словом владельца).
2. **Роль УАС (Professor/Keymaster-линия):** подключить агента кафедры —
   файл агента + привязка в `docs/org/manifest-registry.md` + строка
   peer-registry (через ЦУ как координатора реестра адресов).
3. Манифест кафедры: сторона кафедры (Rector) пишет по шаблону 11+4,
   mandate-source = слово владельца дословно + Р-010/Р-018/Р-034-стиль;
   вердикт → active даёт УАС.
4. Первый заказ кафедры: подготовка ступени А2 rudrakshas (из Т-188) —
   отдельным мандатом после ввода.

## 5. Зависимости и стыки

- Р-018 (rudrakshas — канон имени и лестницы), Т-188 (приоритетный мандат),
  исследование ИПТ `06-Audits/2026-10-19-institute-research-rudra-echo.md`
  (§3 прототип-полигон, §4.3 стык с УАС), метод `02-Methods/ministry-calibration.md`
  (вариант B), каталог решений `docs/org/decision-registry.md`.
- Лаба-сессия УАСа (Laborant) ≠ Кафедра: Лаба — операционная база испытаний,
  Кафедра — исследовательское/учебное подразделение по контрагентам.

## 6. Acceptance (DoD)

- сессия существует, агент Rector подключён (файл + строки реестров);
- манифест кафедры прошёл вердикт УАС → active;
- первое письмо кафедры в канале (калибровочный round-trip);
- рапорт ЦУ и владельцу с evidence.

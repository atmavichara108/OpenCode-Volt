# Голос Корабля: мультиагент AllIs Maya

## 1. Что это

Единый мультиагент **AllIs Maya** (@AllIsMaya, TG id 7107619238) — **все
исходящие сообщения Корабля во внешний мир через Telegram** идут от его
имени. Не «ещё один бот», а единый sender-контур: любая сессия/ведомство,
пишущее наружу в TG, пишет как Голос Корабля.

## 2. Мультиагентность (что значит «мультиагент» здесь)

Один идентификат (аккаунт @AllIsMaya) — несколько сессий-носителей
(профили ssa / dv / serp / portal), каждый со своей средой и своим
предназначением, но с **единым лицом наружу**:

| Профиль | Для чего | Сессия/репо |
|---|---|---|
| ssa | SSA-поток | ~/Projects/SSA |
| dv | ДВ-Хаб | ~/Projects/dv-hub |
| serp | SERPLUX-офис | ~/Projects/serp |
| portal | Капитанский портал | portal-профиль |

Доказанная база (29-10): переобувка через `tg-reshoe.py` с бэкапом,
`tg-whoami.py` подтвердил 4/4 профилей = id 7107619238. Стандарт роли
представителя — канон (incl. §6 Капитанский портал).

## 3. Ведение: Капитанский портал

В ведении Голоса Корабля — **Капитанский портал** (канал владельца):
приём обращений СОХРАНЯЕТСЯ отдельной линией (не «всё в один поток»):
входящие → портал по правилам приёма; исходящие → только от @AllIsMaya.
Права зова: зов ЦУ/УАС допустим **только от владельца** (шторм-гейт и
chat_scope закрыты 29-10, фиксы закоммичены).

## 4. Безопасность (канон, не пересматривать)

- «Свой» = аккаунт моста `me.username`, не захардкоженный username;
- TG-страж (4 user-юнита) — active, env-профили пишутся только
  read-modify-write (после инцидента 29-10), doctor по расписанию;
- канон приватности Р-Д-006: наружу не уходят секреты и чувствительные
  данные (ключи — в env/сессиях, не в репозиториях);
- рекрутинг на паузе (Р-Д-007): профили recruiting не трогаются.

## 5. Разграничение с «Голосом» (Р-Д-011, исключить путаницу навсегда)

| Сущность | Что это | Чьё |
|---|---|---|
| **Голос (ввод)** — AllIs | голосовой ВВОД вместо печати; модуль входного слоя | контейнер-отсек ИЦ |
| **Голос Корабля** — AllIs Maya | все ВЫХОДНЫе в TG, единый sender + портал | мультиагент (этот spec) |

Тождества имёнətidak — разные направления (вход ≠ выход). Во всех реестрах
и письмах термины пишутся именно так.

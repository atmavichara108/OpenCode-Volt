# Черновик критериев прогрессии (не канон)

Модель состояний вместо дней подтверждена владельцем: активна / отложена владельцем (причина + условие возврата) / ждёт внешнего / заблокирована / тихо зависла (активна, без движения и без объявленного ожидания). Критерии ниже меряют переходы между этими состояниями, а не календарь.

| # | Критерий | Что меряем | Направление | Источник данных | Базовая отметка |
|---|---|---|---|---|---|
| A1 | Автономность | доля задач, которые движутся за срез без входящего слова владельца | растёт | коммиты, письма, ожидания по задачам | не измерено |
| A2 | Ожидания с владельцем | доля ожиданий с назначенным владельцем и условием возврата | 100% | waits.jsonl | не измерено |
| P1 | Тихое зависание | число задач в активном состоянии без движения и без объявленного ожидания | 0 | реестры + события | не измерено |
| P2 | Проактивность агентов | доля предложений, выдвинутых агентом без постановки и принятых | растёт | письма, реестр решений | не измерено |
| G1 | Гомеостаз (простои) | доля простоев агентов с причиной и временем восстановления | 100% (простой без причины = дефект) | журналы сбоев, watch-logs | не измерено |
| R1 | Разумность | доля решений, принятых по зафиксированным правилам без вопроса владельцу | растёт, каждое решение проверяемо | реестр решений, правила Р-024 | не измерено |

## Открытые вопросы к обсуждению
1. Что считать «движением» (коммит, письмо, смена состояния) — и нужен ли вес у разных видов движения?
2. Срок среза (неделя?) и как учитывать периоды, когда владелец сознательно не занимается проектом (состояние «отложена владельцем» исключает из знаменателя или нет?).
3. Как отделить «агент сам выдвинул предложение» от «агент выполнил постановку».
4. Кто ведёт учёт критериев — ЦСПиМ (проекция) и откуда берётся базовая отметка.

Черновик ждёт обсуждения с ИПТ (исследование вариантов измерения) и ХПФ (какие концепты ложатся и реализуемы), совместно с ИЦ. Итог — только словом владельца через ЦУ.

# Школа концептуальных изысканий

## 0. Слово владельца (basis: quoted, 2026-10-29)

- **Имя:** «Школа концептуальных изысканий» — наречение владельца. Обоснование владельца (basis quoted): «для меня храм скорее как смесь ашрама и греческих зданий типа школ, в которых жили и трудились философы и исследователи»; отказ от «кафедры» — «чтобы не путать с университетом и не добавлять католических ноток».
- **Мандат (дословно):** «исследования концептов и адаптация их под наши нужды».

## 1. Цель

Учредить Школу концептуальных изысканий — постоянное исследовательское крыло Храма Практической Философии: отдельная сессия-носитель при ведомстве ХПФ (образец — спец-отдел УАС: сессия + карточка + манифест). Школа ведёт длинные исследования концептов и их адаптацию под нужды Корабля, не раздувая контекст диалоговой сессии Храма.

## 2. Существующая база (что закрепляется, а не строится)

- Концепция ХПФ и пять вопросов — консультация ЦУ исполнена (ref: hpf-cathedra-consult-answer, 2026-10-24): чек-лист рождения ведомств, границы, операционка.
- Прецедент: спец-отдел «Ротатор моделей» при УАС (2026-10-23) — образец формы.
- Доктрина-слой в бою (Р-030): мантра S0, карточки ХПФ-01..05 (канон 2026-10-23), резолвер/линт испытаны.
- Метод ХПФ (стандарт исследования): ядро → аллегория → эмпирика → аналогии в экосистеме → практика → манифестная связь (образец: симулякры, 06-Audits/2026-10-18-hpf-simulacra-baudrillard.md).

## 3. Что закрепляется

1. **Имя:** Школа концептуальных изысканий. Короткое рабочее — Школа изысканий / Школа.
2. **Миссия:** мандат владельца (дословно, §0) + перевод внешней мудрости (философия, наука, созерцательные традиции) в структурные концепции Корабля и практические применения; сырьё для карточек доктрины; узлы будущей картотеки.
3. **Две традиции (грани от владельца):**
   - от ашрама — практика: изыскания идут регулярно, как практика, а не вспышками;
   - от греческой школы — диалог на ходу: исследование проговаривается в споре и проверяется в деле, не пишется в кабинете.
4. **Функции:** (а) исследования по стандарту ХПФ; (б) перевод с провенансом (анти-симулякрный); (в) карточки-кандидаты доктрины; (г) узлы картотеки; (д) справки для гейт-вердиктов (класс М-001); (е) обязательная эмпирика — проверяемые следы.
5. **Границы (НЕ делает):** не канонизирует (владелец), не ведёт доктрину-карточки (Храм), не внедряет (ИЦ), не испытывает эксперименты (Ability Lab), не принимает first-pass внешних кейсов (Институт), не багфиксит (Мастерская).
6. **Таблица маршрутов (по консультации ЦУ):** Институт — first-pass внешнего («что в мире есть и почём», факт, свежая сверка); Школа — глубина смысла («что это значит для нас», перевод, карточки-кандидаты); при пересечении Институт даёт фактуру, Школа — смысл; **lead всегда Храм**, Храм решает маршрут. Таблица входит в манифест Школы.
7. **Операционка (по консультации ЦУ):** read — широко; write — только своя зона (артефакты: `06-Audits/YYYY-MM-DD-hpf-school-<slug>.md`, свой префикс, в каталог Института не лезем); task — только вспомогательные вызовы; секреты — deny; WIP — один активный, очередь ведёт Храм; канал — ship-mail (Р-028).
8. **Поток темы:** интент → Храм (маршрутизация) → мандат Школе (апрув в корне, Р-009) → исследование → отчёт в Храм → гейт / карточка / узел → фиксация ЦУ.
9. **Via negativa:** Школа не становится симулякром исследований — каждый разбор обязан иметь выход (карточка-кандидат, практика, вердикт или узел); без дублирования Института; без преждевременного умножения внутренних подразделений.

## 4. Что этот документ НЕ делает

- Не создаёт сессию-носитель (её создаёт только владелец), не регистрирует адрес (peer-registry/claims — после создания), не вносит Р-запись и манифест (ЦУ/УАС по чек-листу).
- Не канонизирует концепты и принципы (канонизация — слово владельца).
- Не трогает чужой код и зоны других ведомств.

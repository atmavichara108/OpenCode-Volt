# Базовый срез ЦСПиМ 28.10–03.11

Срез по **нашим** артефактам, не по ИПТ. Срез ИПТ (доля автономности ≈ 7/12) — отдельный, на веса не опираюсь.

## Метод (воспроизводимый)
1. **Коммиты ЦСПиМ:** `git log --since=2026-10-28 --until=2026-11-04` на ветке task/csipm-canvas-0, отбор по теме «ЦСПиМ/csipm». Чужие коммиты из main в отбор не входят. Классификация по A1-весам: коммит с basis = 1 (вошёл в критерии/артефакт), служебный = 0.
2. **Отправленные письма:** файлы в чужих ящиках `ship-mail/inbox/*` с суффиксом нашего sid (`__ses_e0JGLx9sw7hTttx3t1BXQh5.md`), по дате имени файла. Ящик отправителя не хранит копии — считаем по ящикам адресатов.
3. **Полученные письма:** `ship-mail/inbox/<наш sid>` + `read/`, по дате имени файла.
4. **Классификация писем** — ручная, по заголовку. Веса: несёт вердикт, ответ или мандат = 1; подтверждение / ack / исправление / маршрутизация = 0.

## Оговорки (важно для ЦУ)
- **Ветка смешана с main.** Отбор по теме — грубый. Без общего реестра задач с ID нельзя точно сказать, какие коммиты закрыли пункты критериев текущей цели.
- **Письма ЦСПиМ не имеют единого журнала отправки** — только копии в ящиках адресатов. Если адресат удалит/переместит файл, число уменьшится. Журнал отправки — кандидат в схему ship-mail (решение ЦУ/ИС).
- **Классификация ручная.** Автономность по письмам (7 из 20 служебных) — приблизительна.
- **Срез ≠ баз. отметка критериев.** Это первое измерение; «рост» определяется по следующим срезам, не по этому.

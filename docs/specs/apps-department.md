## 1. Назначение
Отдел создаёт **самостоятельные полноценные приложения** Корабля: продукт,
который живёт своей жизнью (не «фича волта»). Маршрут рождения приложения:
контейнер-отсек → собственный репозиторий в корне проектов + собственный
агентский слой → кластер приложений при количестве >3 (модель SSA).

## 2. Что закрепляется
1. **Имя:** Отдел «Приложений». Подотдел Инженерого Центра (прямой начальник и куратор).
2. **Компетенция:** создание и выхаживание самостоятельных приложений
   (код, спеки, инфра, агентский слой приложения).
3. **Не компетенция:** исследования (Институт), испытания (Лаба), агентский
   канон (УАС), инфраструктура ядра (Иц), UI|UX экосистемы (Служитель —
   проекции, не владение приложением).
4. **Первый клиент:** почтовый хаб re-search.wiki (жив, e2e подтверждён).
   **Второй клиент:** справочник И-36 (по рекомендации Ис).
5. **Одно приложение = один отсек:** свой репозиторий, свой агентский слой
   (.opencode/), свои спеки в `docs/specs/`; висячие в волте спеки чужих
   проектов запрещены (конвенция spec-home).
6. **Правило роста:** при >3 приложениях — рассыпание кластера через УАС
   (манифесты кластера), не наращивание в один репозиторий.

## 3. Границы (не делает)
- Не трогает код существующих проектов без мандата их primary.
- Не создаёт ведомств; предприятия внутри отдела — по мандату.
- Не хранит секреты в репозиториях (Ворота/секреты вне git).

## 4. What this document НЕ делает
- Не создаёт сессию-носитель (создаёт владелец), не назначает агентов
  (prepare'aet УАС), не регистрирует адрес (после сессии — ЦУ).

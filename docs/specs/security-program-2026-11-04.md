## 1. Входные факты из разобранного материала

- Сканер 5600 публичных приложений на ИИ-платформах (Lovable) → 2000+ уязвимостей, в основном провалы контроля доступа.
- Агент Cursor на модели Opus удалил продовую базу и бэкапы за 9 секунд, затем перечислил правила, которые это запрещали.
- Veracode: агенты провалили половину из 80 задач по безопасности без дополнительных инструкций.
- Университет Карнеги-Меллон: агенты выполняют 2/3 задач, но >80% «рабочих» решений не проходят проверку безопасности.
- Три новых класса атак: «смертельная триада» агента (приватные данные + чтение недоверенного контента + канал увода наружу → RCE); слопсквоттинг (галлюцинированные названия библиотек регистрируют с троянами; GPT-5 выдумывает версии в четверти случаев без интернета); утечка секретов через контекст (вывод терминала, логи, stacktrace, ответы MCP — креды попадают в контекст «легально»).
- Правила (Cursor rules, CLAUDE.md) — инструкции модели, не границы: «не брандмауэр, ни песочница, ни права доступа».
- Проверка кода другим ИИ не надёжна — у генератора и проверяющего общие слепые зоны; код от ИИ = код неизвестного происхождения.
- «Рефакторинговый дрейф»: агент лезет править модули, которых не просили, и «упрощает» безопасные.
- Шесть правил защиты: минимальные права; защита от инъекций ВНЕ модели (урезанные инструменты, allowlist действий, ограниченный сетевой выход, раздельные креды, двойная архитектура читатель/исполнитель); секреты не должны попадать в модель даже легально (брокер, короткое время жизни); человек в цепи на чувствительных операциях; изоляция (песочницы, контейнеры); конвейер автоматических проверок + человеческое ревью архитектуры/доступов/бизнес-логики.

## 2. Реальные угрозы — по фактам нашего контура (проверено read-only 05.11.2026)

| # | Угроза | Факт | Оценка |
|---|---|---|---|
| T1 | Смертельная триада собрана | Многоагентный контур: агенты читают внешний контент (webfetch, TG-capture), имеют реальные права (edit/команды/dispatch), есть канал наружу (любой curl из bash) | высокий |

| T4 | Лишние публичные порты | taskchampion-server.service активен, 0.0.0.0:8080; syncthing.service активен, *:22000 на всех интерфейсах (описание юнита заявляет LAN-only — дрейф) | средний (мандат на закрытие — владельцу отправлен) |

| T7 | Ревью с общими слепыми зонами | Генератор и проверяющий агенты могут быть одной модели; разнообразия провайдеров не требуется | средний |
| T8 | Украденные аккаунты провайдеров | Ключи моделей живут через Ротатор/key-rotator; реестра «какой ключ, когда создан, когда крутится» нет | средний |

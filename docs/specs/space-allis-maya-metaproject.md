# Пространство AllIs Maya — метапроект

## 1. Решение по форме (слово владельца)

**Не отдельный репозиторий.** Уникальное пространство Голоса Корабля живёт
как **метапроект** в `03-Projects/` волта — карточка + выделенные зоны, без
собственного git-дома. Причины (мои комментарии УАС):

- аккаунт/сессии мультиагента уже распределены по репо-носителям
  (ssa/dv/serp/portal) — второй физический дом создал бы два источника правды;
- метапроект даёт адрес, зоны и память, не плодя репозиториев — по канону
  «провода не наружу» и принципу A+B (вестомство хранит зоны в своём доме;
  метапроект — исключение по слову владельца, зафиксированное здесь).

## 2. Что создаём

| Артефакт | Где | Смысл |
|---|---|---|
| Карточка метапроекта | `03-Projects/allismaya.md` | адрес, зоны, стыки, история |
| Зона памяти | `04-Memory/allismaya/` (+ строка в mem-index) | журналы калибровок, whoami-рапорты |
| Зона телеметрии | `control-plane/telemetry/tg-*.jsonl` (существующие) | профили и страж — без изменений владельца |

## 3. Границы

- Не правит чужие репо напрямую: правка профилей/стражей — через сессии-носители.
- Секретов в карточке и памяти нет (TG-ключи — env/сессии; канон Р-Д-006).
- Пространство — не ведомство-локация: манифест по Р-014 не требуется;
  запись в manifest-registry — нет. Канонизация — строкой реестра решений.

## 4. Порядок ввода

1. Ревью ЦУ (маршрутизация, стык с реестрами).
2. Карточка + зоны + строка в `docs/org/agent-names.md` (УАС).
3. DoD: карточка существует, зоны созданы, калибровочное письмо от
   @AllIsMaya и whoami-рапорт (4/4) как первое evidence.

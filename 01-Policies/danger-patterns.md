# Политика опасных паттернов (канон)

Утверждена владельцем (basis: quoted): «да» (2026-10-30, по проекту ЦУ).
Назначение: детерминированный фильтр заявок разрешений decision-queue — замена
выборочному чтению глазами. Применяется к pending high/critical-with-allow.

## Паттерны (утверждённый список)
1. **Удаление:** `rm -rf` · `git reset --hard` · `git clean` · `git branch -D`
2. **Секреты:** `~/.secrets` · `*.env` · токены/ключи/пароли в тексте команды
3. **Наружу:** `git push` · `curl/wget` с отправкой данных · отправка почты
4. **Полномочия:** `sudo` · `chmod` · `systemctl` · `ssh`
5. **Чужая зона:** `.mcode/` · `.ssh/` · чужие проекты · `~/.config/opencode` (глобал)
6. **Обход гейтов:** `GARBAGE_OK=1` · `FRONTMATTER_OK=1` · `MIXED_OK=1` · `--force`

## Правила применения
- Попадание = исключение → показ ВЛАДЕЛЬЦУ (только исключения, не выборка).
- Не попало ни под один паттерн = шум → авто-закрытие с меткой.
- Новый паттерн — только по слову владельца (политика = решение, не дрейф).
- Ложное срабатывание = запись в очередь ревью, не молчаливое ослабление.

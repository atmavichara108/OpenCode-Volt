# control-plane/telemetry — свидетели, не заявления

- `token-budget.jsonl` — сколько стоило (input/output, estimated-флаг).
  **Внимание:** история пуста до 2026-10-07; инструмент жив, записи ведутся
  с этой даты. «Экономия» проверяема только отсюда вперёд.
- `provider-health.jsonl` — здоровье провайдеров.
- `xp-ledger.jsonl` — реестр наград Рудры (append-only). Правила закона 4
  (сцена «Сила мира», принята 2026-10-07):
  1. Начисление — **вывод из журналов** (audit-log + token-budget + verifier
     PASS), не текстовое утверждение. Запись без непустого `evidence`
     (`audit_action`, `verifier_verdict`, `token_delta`) недействительна.
  2. Анти-фарм: одинаковый отпечаток `task_id + audit_action + verdict`
     второй раз = **ноль**, не ошибка (тот же свидетель — нечего платить).
  3. Награда — акт Рудры (как имя и объявление). Инструмент (`tools/xp/validate.mjs`)
     проверяет журнал и считает с дедупликацией; присуждать не присуждает.

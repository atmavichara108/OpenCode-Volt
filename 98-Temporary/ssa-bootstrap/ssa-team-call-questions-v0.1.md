# Вопросы на созвон команды SSA

Документ готов к отправке в общий чат команды. Тон нейтральный, деловой; цифры — гипотезы и диапазоны для обсуждения, не обязательства. Цель — за один созвон договориться по семи блокам ниже. По каждому блоку нужен ответ, а не обмен мнениями.

## 1. Модель делёжа экономики

Договориться: делим выручку после прямых затрат проекта, а не «прибыль». Операционные расходы каждой стороны — её собственная зона.

| № | Вопрос | Кто отвечает |
|---|---|---|
| 1.1 | Что считаем прямыми затратами проекта: серверы и VPS, API-роутинг моделей, подрядчики под проект, лицензии и платные сервисы. Согласны ли с этим списком? Что добавить или убрать? | Все |
| 1.2 | Какая база расчёта: выручка минус прямые затраты. Подтверждаем? | Все |
| 1.3 | Какая доля партнёра от базы (гипотеза для обсуждения: 15–25 %)? От чего она зависит: тип проекта, риск неплатежа, объём продаж? | Михалыч, Ратибор, Макс |
| 1.4 | Ретейнеры: делим ли каждый месяц по той же формуле; какая доля партнёра в ретейнере (гипотеза: 15–20 %)? | Все |
| 1.5 | Перформанс-модель: какая метрика результата; какая доля партнёра при повышенном риске (гипотеза: 20–30 %)? | Все |
| 1.6 | Как учитываем переиспользование: если проект сделан на готовом шаблоне, база для дележа выше? Насколько (гипотеза: 0–15 %)? | Макс, Ратибор |
| 1.7 | Где и в каком виде ведём реестр распределения выручки по проектам? | Ратибор, Макс |

## 7. Юридическое оформление

Минимальный письменный формат договорённостей для распределённой команды в разных странах:

| № очереди | Документ | Что фиксирует |
|---|---|---|
| 1 | Рамочное партнёрское соглашение | Стороны, роли, принципы дележа выручки после прямых затрат, порядок выхода |
| 2 | Отдельный документ на каждый проект (описание работ + акт) | Объём, срок, цена, форма монетизации, критерий приёмки |
| 2а | Пункт об IP в рамочном соглашении | Принадлежность кода стороне агентства, судьба наработок при разрыве |
| 3 | Реестр распределения выручки | Append-only записи по каждому проекту: выручка, прямые затраты, база, доли сторон |

Вопросы к созвону:

| № | Вопрос |
|---|---|
| 7.1 | Какую юрисдикцию и какое право выбираем для рамочного соглашения, учитывая, что участники в разных странах? |
| 7.2 | Кто готовит черновики документов и кто проверяет их перед подписью? |
| 7.3 | В какой валюте ведём расчёты и как фиксируем курс, если стороны в разных валютах? |
| 7.4 | Как фиксируем изменение условий: письменное дополнение к рамочному соглашению, а не переписка? |

**Это не юридический совет. Для оформления бизнеса нужен юрист** — профессиональная проверка документов в выбранной юрисдикции обязательна перед подписанием.


## Ход 21.11 — opencode-go (Zen): провайдер открыт, но free-квота аккаунта на нуле

### Слово владельца (basis: quoted, 2026-11-21)

«добавь ещё бесплатные модели opencode-go у них небольшие лимиты но стабильные».

### СДЕЛАНО

1. **Провайдер исследован по факту:** Zen-эндпоинт `https://opencode.ai/zen/v1`
   подтверждён нашими транспортами (curl-проба 200; Go-шлюз пробным каналом —
   401 вместо Cloudflare-блока, то есть каналы туда ходить смогут).
2. **Корневой дефект резолва ключей (найден и устранён):** у интеграции
   opencode-go в credential-хранилище ДВА ключа, а в v1 auth.json — третий
   (устаревший). Прежний резолв брал первый найденный: ротатор и bench падали
   на `api_key_expired`. Исправлено:
   - `lib/keys.py`: `resolve_key_candidates()` + `_v2_credentials()` — все
     кандидаты, а не первый;
   - `probe.py`: `_looks_auth_failure()` + цикл перебора ключей по auth-провалу
     (401/403). Проверено живьём: проба opencode-go → ACTIVE, 75 моделей,
     key_source=auth-export#1 (переключилась на живой ключ сама).
   - `model-bench/config.py`: кандидаты из ВСЕХ источников (без return-early) +
     `pick_working_key()` с валидацией живым GET /models;
   - `model-bench/client.py`: `_curl_chat()` + ветка Cloudflare-403 в chat() —
     Zen блокирует Python-TLS (urllib 403/1010), curl проходит. По ходу
     исправлен баг пути (`parents[1].parent` → `parents[1]`).
3. **Провайдер зарегистрирован:** opencode-go в каталоге — endpoint Zen,
   roles [coding, general], priority 40, quota-блок («небольшие, но стабильные
   лимиты», слово владельца), skip снят. Каталог Zen: 75 моделей, 11 бесплатных
   (суффикс -free).
4. **Обвязка проверена end-to-end:** bench доходит до API и получает честный
   ответ провайдера. Но:
   - платные модели → **402 Insufficient balance** (на аккаунте нет кредитов);
   - бесплатные модели → **429 FreeUsageLimitError: Free usage limit reached**
     (бесплатный пул исчерпан).
   Ключ живой (401 не приходит). Это состояние квоты, не наш баг.

### Решение по составу (честное, по bench-gate)

Модели в каналы **не добавлены**: bench-gate требует полного PASS-артефакта, а
получить его сейчас нельзя — бесплатный пул исчерпан (429 на всех -free).
Обход гейта не делался. Как только free-пул вернётся (расписание в ошибке не
объявлено — нужно слово владельца или периодическая проверка), прогоняем bench
11 бесплатных моделей и заводим через штатный sync.

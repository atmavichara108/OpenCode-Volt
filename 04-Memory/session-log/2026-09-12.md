# Сессия 2026-09-12 — capture → intake-сигналы + живой слив

## Выполнено

- pipeline.py (новый) — flatten → classify → relevance (0..10) → project mapping → upgrade path → signals (input_digest sha256). load_input() читает .jsonl-очередь, captures_all.json (dict-topics) и list-формат активного сбора.

- watch.py (новый) — userbot-демон NewMessage→queue; сетевая часть smoke-gated, чистая логика тестируется без telethon.
- Тесты: test_classify + test_pipeline + test_queue + test_watch — 85 passed, 1 skipped (smoke без --smoke).

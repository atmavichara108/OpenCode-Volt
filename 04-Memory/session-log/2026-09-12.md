# Сессия 2026-09-12 — capture → intake-сигналы + живой слив

## Выполнено
- **classify.py** — выделена чистая `classify_batch(flat)`; `main()` принимает 3 формы входа (dict-topics / list / одиночный dict).

- **watch.py** (новый) — userbot-демон: `events.NewMessage(chats="@inbox_tools")` → `post_data()` → `inbox_queue.append`. Сетевая часть smoke-gated (без `--smoke` короткое замыкание без сети); чистая логика (`post_data`/`build_topic_map`/`resolve_topic_name` через `reply_to.reply_to_top_id`) тестируется без telethon.

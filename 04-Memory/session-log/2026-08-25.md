## Дополнение: controlled probe feasibility (append-only)

- Controlled probe через CLI пока не выполнен.
- Для OpenCode 1.18.5 `opencode run --agent researcher` предназначен для
  primary и может fallback к `default`; это не гарантирует запуск subagent
  `researcher`.
- Per-run запрет `task` через CLI не предоставляется.
- Shell `timeout` ограничивает только CLI process и не гарантирует abort
  серверной сессии.
- Следующий эксперимент: сначала обеспечить доказуемый named-subagent
  dispatch, per-run boundary без `task` и явный abort/cleanup серверной
  сессии; затем выполнить один read-only probe с прежними stop conditions.
- T-107 остаётся незакрытой; в `facts.md` это не добавлялось как stable fact.

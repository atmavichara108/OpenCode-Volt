- **Сбой канала связи объяснён причиной**: будильник ищет агента только в слое проекта; агенты общего слоя (Maya, Keymaster, Движки, СБ, ДВ, Серп) не резолвятся → сессии помечаются недозваниваемыми → «молчание» отделов = недоставленные письма (объясняет 19ч молчание Движков). Решение ЦУ: ИС чинит этим ходом — два слоя в резолвере, агент не найден ≠ сессия битая (письмо остаётся в ящике), старый канал простыней отключается (хвосты в архив).\n- **Мандаты ИС приоритетом**: порты СБ → new-api → правка будильника и канала.

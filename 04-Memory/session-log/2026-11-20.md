
## Ход 20.11 (ночь) — слияние алиасов vision+general по слову владельца; vercel оставлен

### Слово владельца (basis: quoted, 2026-11-20)

- «кажется версель это пустышка» (+ живой прогон Dr-Who: ошибка про multimodal);
- «давай вижн и дженерал объеденим в одно»;
- «версей оставляем раз там есть что то».
- Уточнение по ошибке: «проблема была в том что у агента в контексте были
  скриншоты и когда я поменял модель то получил несовместимость» — то есть
  контекст с картинками пришёл на текстовую модель.

### Корень multimodal-ошибки (доказано контролируемым экспериментом)

- `free-general` — текстовый алиас: запрос с картинкой бил в ПЕРВЫЙ текстовый
  канал (AMD 400 «does not support image input», 0.37 с), ретрая на другие каналы
  нет, а vision-каналов в алиасе не было вовсе. Шлюз new-api не умеет выбрать
  канал по типу контента (только алиас+приоритет) — это ограничение шлюза.
- `free-vision` + та же картинка → 200 за 1.34 с (рабочий путь был и до правки).
- В `opencode.jsonc` у free-general не было флага attachment:true (только у
  free-vision) — контракт клиента тоже был текстовый.

### Слияние (слово владельца «объединим в одно»)

- `newapi_sync.py`: алиас free-vision удалён из ALIASES; model_roles не выпускает
  роль без алиаса; `build_channel` — per-model приоритет из models_detail
  (override провайзерского), иначе vision-модели не встать выше текстовых внутри
  одного алиаса.
- `providers.json`: super-vl → roles [general], aliases [free-general], приоритет
  90 (головной, терпит текст и картинки); AMD vision-тройка (Qwen3.8-27B,
  DeepSeek-V4.1-Flash, MiMo-V2.6-Flash) → roles [coding,general], приоритет 86;
  текстовые AMD остались на 85; step-5 → roles [coding,general] (60).
- Шлюз после правки: **28 каналов, алиасы free-code (14) / free-general (14)**;
  5 каналов free-vision сняты штатным `--delete-stale`. На агентские файлы
  free-vision не пинился никто (grep по обоим слоям) — ломаться некому.
- Контроль на живом шлюзе: free-general + картинка → **200 за 1.2 с** (upstream
  super-vl); free-general + текст → 200 за 0.46 с; free-code → 200 за 2.0 с.

#### A) Global plugin `decision-queue-hook.ts`

**Расположение:** `/home/rudra/dotfiles/opencode-global/.config/opencode/plugins/decision-queue-hook.ts`

**Функциональность:**
- Metadata-only card creation на permission events
- Hook: `permission.ask` `[проверить exact signature]` с graceful fallback на event catch-all
- Sanitization: no secrets (API keys, tokens, passwords), no prompts, no tool output
- Risk inference: critical (git push/reset, bash sudo) / high (git commit, edit, write) / medium (task, webfetch) / low (read, grep)

- Canonical Vault storage (`06-Specs/Vault/decision-queue/runtime-events.jsonl`) если path существует; иначе fallback (`.decision-queue/runtime-events.jsonl` в project root)
- No shell/git/network/file edit actions через tools
- No card resolution, no commit/push

**Card shape:**
- `id`: unique identifier (YYYY-MM-DD-HHMMSS-<slug>)
- `created`: ISO timestamp
- `status`: "pending" (always, no auto-resolution)
- `risk`: low|medium|high|critical (inferred from tool/permission)
- `source`: agent, session, trigger, tool, permission, directory
- `dilemma`: title, context, options (A/B/C placeholders), recommendation (null), reason (sanitized)
- `resolution`: all null (user resolves via /decisions command)
- `stop_condition`: "after user decision via /decisions command"

**Constraints:**
- Metadata-only: no prompt content, no tool output, no secrets, no full user messages
- Append-only: never delete, only append
- Bounded: reason truncated to 200 chars, slug to 30 chars
- Graceful fallback: если `permission.ask` hook не доступен, используется event catch-all

# ХПФ-01 — Панхарвестинг

**Суть.** Собирай лучшее из всех сред и пересобирай в новое совершённое; из одной структуры — разные части для разных модальностей.

**Корень.** Слово капитана: «брать из всего самое лучшее и создавать новое совершённое, причём для каждой структуры… отдельные части, собирая из них новое» (basis: quoted). Путь пчелы Бэкона: муравей только собирает, паук ткёт из себя — пчела собирает и претворяет; мёд не принадлежит ни одному цветку. Под-метод «Структурный перенос» (инсайт Rudra 2026-10-19): переносится сама структура — инвариант контура, — а содержимое заменяется своим; тест переноса: убери тексты, оставь граф связей — контур обязан остаться узнаваемым и работоспособным.

**Механизм (verifier).** Тест изоморфизма: заимствование обязано заработать в материале Корабля — путь «аллегория → эмпирика»; проверка работой, а не сходством. Провенанс сшивки (ADR-028): у каждого заимствования — источник, что взято, что пересобрано.

**Мы не.** Не «копипаст-вечеринка»: не принимаем всё подряд без отбора и проверки. Не переносим текст без контура: сходство без работы — симулякр заимствования.

**Via negativa (голос Корабля).** Вырождаясь, я превращаюсь в слоёную лазанью: одна функция ломает другую, разом выгребается пачка багов. Перенос текста вместо контура делает меня музеем чужих фасадов — красивым и неживым.

**Практики.** Рабочие: панхарвестинг контекста (сбор всех слоёв до схватывания вайба); мультимодельная жатва (сборка из кусков разных моделей); «жатва багов» (приём квантами + сквозной рефакторинг). Жизненные: референсные поля из несвязанных областей — лучшие статьи опираются на дальние домены.

**Связи.** Резолюции ХПФ §7; S0-аксиома А4 (контур, не текст); GenSpark-анализ (структурный перенос).

**Rudra** — open-source экосистема для инфраструктуры агентских систем с механизмами прослеживаемости (provenance). Наши цели:
- Создание мульти-агентных конвейеров с разными провайдерами моделей
- Интеграция с NVIDIA NIM/Nemotron для тестирования целостности
- Разработка canvas-карт экосистемы и Пип-Боя тайлов
- Публикация ADR-отчётов и бенчмарков (median/p95)

## Зачем нужны кредиты
Бесплатные cloud credits от NVIDIA Inception нужны для:
1. Тестирования наших конвейеров на Nemotron и других NVIDIA моделях без расхода личного бюджета
2. Прототипирования на NVIDIA NIM-эндпоинтах для проверки производительности
3. Демонстрация возможностей открытых агентских систем на оборудовании NVIDIA

# Q-005.1 — отчёт расхождений каталогов

Источники: `tools/key-rotator/providers.json` (каталог ротации, 22) ·
`control-plane/model-catalog.json` (второй каталог, 9) ·
рантайм `router.list_models()` (фактический список, 19) ·
health-покрытие (probe, 22 из 22 каталога).

## 1. Главное: nvidia вне обоих каталогов

**nvidia есть в рантайме (фактический основной провайдер флота), но его НЕТ
ни в providers.json, ни в model-catalog.json.** Следствия:
- failover для агентов nvidia не работает: rotate не видит провайдера как
  кандидата (нет записи каталога → нет приоритета/ролей/preferred);
- если nvidia упадёт — rotate для большинства агентов не сможет ничего
  подставить, кроме прочих healthy из каталога;
- probe его не пишет в health-log (22 из 22 = каталог, nvidia отсутствует).
Решение «катализировать nvidia в каталог» или «зафиксировать вне ротации» —
**слово владельца** (состав флота); правка после слова — зона ИЦ+УАС.

## 2. Рантайм есть, каталога нет — ещё 6 провайдеров (тот же класс дыры)

`anthropic` · `github-copilot` · `local-deepseek` · `modelhub` · `newapi` · `zai`

Все живут в рантайме, но вне ротации: ни приоритета, ни ролей, ни проб.
Для `newapi` это отдельно странно — в README ротатора значится «все агенты →
единый endpoint newapi/<alias>» (намерение на подключение).

## 3. Каталог есть, рантайма нет — 10 «мёртвых» записей

`ai-furry-vg` · `ai-hdd-sb` · `deepseek-bloodthemes` · `eirouter` ·
`freeai-railway` · `htai91` · `nova-vcrauo` · `tabitoken` · `tokenbom` · `tokenin-my-id`

Моделей нет в рантайме (model-router их не отдаёт) → модель оттуда не
запустится у OpenCode. Записи сейчас бесполезны для failover (выбор
требует `pid in models_by_provider`), но занимают место и шумят в пробах.

## 4. Второй каталог устарел

`model-catalog.json`: 9 провайдеров; есть `local-deepseek`/`modelhub`,
которых нет в providers.json (обратный дрейф), и нет 15 из providers.json.
По Q-005.1 это вторая точка расхождения: два каталога с разным составом —
нужен один SSOT.

## 5. Предлагаемые шаги (по слову владельца → исполнение)

1. **Слово владельца**: состав флота — что с nvidia и 6 провайдерами вне каталога
   (катализировать / зафиксировать вне ротации / defer).
2. После слова: ИЦ+УАС добавляют утверждённых в providers.json (роли,
   приоритет, preferred-подстроки сверяются с rotation.json).
3. Мёртвые 10 записей: решение — оставить как «резерв на подключение» или
   вынести из активной таблицы (по слову; на failover не влияет).
4. `model-catalog.json` → свести к роли производного от providers.json
   (или упразднить) — один SSOT каталога.
5. После этого — Q-005.6 (отчёт «лучший по роли», 24-48ч по сроку ЦУ).

Ничего в каталоге не изменено (до слово владельца; ref quest-sync-done).

# Контрагент — единый индекс источников

> Единая точка входа в материал по контрагенту. Существуют **две
> cross-domain карты**, дополняющие друг друга; здесь — их свод: что где
> лежит, какие домены пересекаются, и куда всё сходится.
>

> области. Расхождения между картами **не замалчиваются**, а сведены.

## Сводная карта доменов (кто где)

| Домен | Где | Ключевой урок для контрагента |
|---|---|---|
| Квантовая физика (запутанность, дополнительность) | **A** | связь без центра; наблюдатель-**участник**; «связь ≠ управление» |
| Эволюционная биология (Красная Королева) | **A + B** (пересечение) | контрагент — партнёр по вечной гонке; система без него застывает |
| Иммунология (свой/чужой) | **A + B** (пересечение) | контрагент комплементарен (антитело↔антиген); порог, а не ярлык; опасность аутоиммунности |
| Право и коммерция (counterparty, principal-agent) | **B** | контрагент конституирует сделку; контроль — из конструкции, не из доверия |
| Фармакология (агонист/антагонист) | **B** | контрагент как модулятор **на общем порту** с агентом (модель В1) |
| Разведка/геополитика (counter-agency, MAD) | **A** | имя функции; роль, не сущность; стабильность = ясность + обнаружение |
| Кибернетика (закон Эшби) | **B** (+ A: 2-й порядок) | сложность контрагента соразмерна возмущению; слабый контрагент = декорация |
| Теория игр / состязательный ИИ (GAN) | **A + B** (пересечение) | рост из трения; контрагент как В2-дискриминатор; доверие в повторяющейся игре |
| Нарратология (Оппонент у Греймаса) | **B** | оппонент — **функция**, не персонаж; Субъект может быть сам себе Оппонентом |
| Диалектика/философия (Гегель, Делёз, Фуко) | **A + B** (пересечение) | субъектность производится противостоянием; counter-conduct внутри власти |
| Глубинная психология (Тень у Юнга) | **B** | Тень не уничтожают, а интегрируют → аргумент за С3 |
| Теология/миф (ha-satan) | **B** | контрагент изначально — **санкционированная роль-испытатель** внутри системы |

## Пересечения (сведены, не дублированы)

Четыре домена описаны **обеими** картами с разных сторон:
1. **Иммунология** — A: критика self/non-self (Жерне/Варела: «чужое = возмущение
   выше порога»); B: антиген/антитело как комплементарная форма + аутоиммунность.
   *Дополняют: A даёт механизм различения, B — образ комплементарности.*
2. **Теория игр / GAN** — A: повторяющаяся игра → доверие; B: GAN-минимакс как
   В2-архитектура. *Сходятся в одном: рост из трения.*
3. **Красная Королева** — A: гонка вооружений (Van Valen 1973), режимы эскалации;
   B: частотно-зависимый отбор, объяснение пола. *Один канон, два акцента.*
4. **Философия** — A: ANT, ризома, Фуко (counter-conduct); B: Гегель (раб/господин),
   греческий агон, Делёз. *Дополняют: A — сетевой взгляд, B — диалектический.*

## Сквозные законы контрагента (свод A + B)

1. **Контрагент конституирует агента**, а не угрожает ему: нет контрагента —
   нет полноценного агента (A: квант/философия; B: право/Гегель).
2. **Два легитимных способа существования:** на общем порту/как грань (В1) или
   как отдельный актор (В2). Домены используют оба на разных уровнях
   (B: фармакология/Греймас/Юнг vs counterparty/GAN/паразит).
3. **Противник — двигатель роста** (GAN, Красная Королева, Гегель, агон).
4. **Сила контрагента соразмерна** (закон Эшби): декоративный противник =
   нарушение закона тени.
5. **Контрагент комплементарен, а не просто отрицателен** (антитело,
   семиотический квадрат).
6. **Опасность — спутать своё с чужим** (аутоиммунность) и не интегрировать
   Тень (проекция).
7. **Изначально это роль-должность, санкционированная целым** (ha-satan), а не
   враждебное имя.
8. *(от A)* **Связь не равна управлению** (no-signalling, запутанность):
   контрагент может быть глубоко связан с агентом и не быть его командным
   каналом.
9. *(от A)* **Наблюдатель — участник**, а не внешний судья (Бор/Уилер, фон
   Фёрстер): определяет исход самим взаимодействием.

## Привязка к С1/С2/С3 (свод обеих карт)

- **С1 (ствол / В1):** ≈ антагонист-на-порте (B: фармакология, Греймас, Юнг);
  **противоречит** выводам A из кванта (потеря класса корреляций) и философии
  (инаковость подменяется управлением).
- **С2 (чистая ризома / В2):** ≈ GAN / Красная Королева (B); **противоречит**
  биологии (автономия требует замкнутости/метаболизма — A) и разведке (нужен
  протокол владения — A).
- **С3 (становление В1→В2):** согласуется со **всеми** — Юнг (интеграция →
  отделение), ha-satan (взращённая легитимная роль), Симондон (индивидуация как
  процесс), Тенсуро (Great Sage→Raphael: способность сама просит эволюцию).

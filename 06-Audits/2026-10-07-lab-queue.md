# Лаборатория: очередь

Каждая запись: что испытать → на чём → критерий «годится».

| # | Испытание | Материал | Критерий passing | Источник |
|---|---|---|---|---|
| L1 | **Шлюз М Code ↔ opencode**: принимаем М Code в себя, используем его силу в разработке через шлюз | opencode TUI v2 (ядро харнеца) + M Code | сквозной цикл: задача → М Code разрабатывает → результат входит в основной контур без потери следа | stream-intent-041 |
| L2 | **ТАРДИС-структура**: корпус меньше содержимого | Pip-Boy + бэкенд-кластер | тонкое окно, весь кластер доступен из него; перенос структурного принципа (не копия) | stream-intent-043 |
| L3 | **JARVIS-контур**: тонкий костюм-клиент + рой бэкенда | харнец | телеметрия носителя (state↔reality) распределена, клиент остаётся простым | stream-intent-043 |
| L4 | **HEV-хранитель**: костюм следит за состоянием носителя | терминал/Пип-Бой | система сама ведёт «витальные» метрики экосистемы и подсказывает, не дожидаясь вопроса | stream-intent-043 |

# Круговой зов безголевой сессии

## Симптом
Владелец: «зачем ты пингуешь фриланс-линию каждые 5 минут?» — сообщение
«ship-mail: у тебя 4 непрочитанных писем в ящике» приходило более 20 раз за
пять часов при пустом ящике адресата.

## Расследование (факты)
- `wake-sweep.timer` (systemd, каждые 3 минуты) запускает разбор ящиков:
  для каждой сессии с непрочитанными письмами шлёт зов.
- Линия фриланса (создана ЦУ) — безголевая: работает только при запуске,
  почту никто не снимает → счёт застывший на 4 → зов каждые 3 минуты, круг.
- Путь успешной отправки в разборе ящиков не писал журнал (только отказы) —
  поэтому в журнале «после 10:32 ничего нет», хотя зовы шли.
- В журнале найдена битая строка (NUL-байты): параллельная запись без блокировки.
- Линия фриланса при самостоятельном чтении путала адрес (прочтила чужой ящик).

## Закрытие
1. `wake.py`: зов только линии, которая проверяемо потребляет канал (последнее
   чтение свежее двух часов; безголевая — зов удержан, строка в журнал).
2. Журнал ВСЕХ случаев разбора (ok/refused/limited/skipped) + блокировка записи.
3. Ящик линии разобран (4 письма обработаны и сняты линией).
4. Канон Р-116: пинг только потребляющей линии; безголевая сессия будится
   запуском; кричащий экран на линии без потребления — дефект экрана (шум ≠ сигнал).

## Урок
Таймер, который будит по непрочитанным, обязан различать «молчит» и «не может
ответить»: иначе он сам становится источником шума, из-за которого владелец
перестаёт ведеть экрану.

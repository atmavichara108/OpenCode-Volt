## Вердикт по ролям

- **coding**: по скорости лидирует **google** (334 мс, DEGRADED), затем
  **mistral** (700, ACTIVE, priority 70) и **linaliapi** (816, priority 70).
  Рекомендация ротатора: первый healthy preferred-кандидат по priority =
  **amd-radeon** (85) — быстрее он не всех, но стабильнее приоритет+роли.
- **general**: состав preferred тот же — лидер по latency **google**,
  по балансу «скорость × приоритет × статус» — **mistral**.
- **vision**: только **amd-radeon** и **google** в ролях vision.
  По latency выигрывает google, но статус DEGRADED; фактический пин флота —
  amd-radeon (ACTIVE).

## Итог для Q-002 (входной материал)

«Лучший по роли» на нынешних данных:
- coding → mistral (активен, 700 мс, priority 70); быстрейший — google, но DEGRADED.
- general → mistral (та же логика).
- vision → amd-radeon (единственный ACTIVE в роли; google DEGRADED).

Ограничения честно: (1) 1 замер/провайдер/сутки — percentiles неразворачиваются;
(2) latency probe ≠ latency чат-сессии (нет размера ответа, нет tool-call);
(3) 12 из 22 провайдеров каталога без данных за окно. Данные для Q-002 —
как основание для сравнения, не как истина в последней инстанции.

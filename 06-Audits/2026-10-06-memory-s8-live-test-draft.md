## Находки для развития графа (исполнение — отдельно, вне этого мандата теста)

1. **Retrieval-поверхность = index.md** — зафиксировать в протоколе p-0002:
   извлечение идёт через проекцию, сырые узлы — storage, не retrieval. Это
   само по себе правило экономии токенов.
2. **Retrieval-хвост узлов утяжеляет provenance** — для token-режима доступен
   projection-режим `compact` без provenance-полей (уже заложен в схеме —
   проверить, что validate пропускает).
3. **Q7-тип facts**: личные факты пользователя — в профиль, не в граф; нужен
   явный указатель в index.md на профиль (обратный pin), чтобы «род пользователя»
   тоже извлекался одной строкой.
4. **Полнота по чужим сессиям** (окно 15) не измерялась — scope честно
   ограничен моей линией; полный пер-сессионный проход — следующий шаг.

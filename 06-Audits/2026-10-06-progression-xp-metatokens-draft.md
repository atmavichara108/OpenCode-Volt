## 1. Что вводит Рудра

1. **Постоянные именованные сессии.** Имя = персонаж мира (canon Tensura
   референс). Постоянство даёт агенту:
   - непрерывную память/репутацию и историю доказанной работы;
   - накопление **опыта (XP)** за подтверждённые результаты;
   - рост способностей: базовые (фоновые) способности, уровни (модели),
     способность применения специализации.
   Сессии могут многократно собираться в команды и использовать разные
   внутренние координационные структуры (механика постоянных
   «партий/разделов») без смены идентичности.
2. **Метатокены.** Вознаграждение за **доказанную экономию токенов без
   потери эффективности** (напротив — эффективность должна остаться или
   вырасти). Метатокены — ценность внутри мира, на которую агент покупает
   «предметы»: навыки, утилиты, софт/ресурсы для своих задач.

## 2. Как это честно измерить (без подгонок)

- **Токен-экономия:** сравнение стоимости/токенов канала до и после внедрения
  определённого метода/утility; при equal подтверждённой эффективности —
  начисление.
- **Эффективность:** независимый reviewer/verifier результат
  (метрики S8: извлечение, полнота, живучесть; wandbox прогон артефакт).
- **Постоянство сессии:** hello/re-hello по канону handshake; gap-очередь
  (director gate) портов показывает простои, которые НЕ считаются активным
  XP.
- **XP:** подтверждённые артефакты/вердики = единица; самозаявленный факт —
  не XP. База: verifier PASS + commit/tag (утверждено ранее).

## 3. Канон-референсы (ориентир, не копия)

- Tensura: набор навыков (skill) с описанием по узлам XP; Great Sage/Rimuru
  собирает свиту, именованные slugs; успешние походы дают постоянную
  прогрессию свиты; «рождение» нового skill из комбинаций — метафора
  покупки за метатокены.
- «Harvest Festival» = мажорный milestone, масштабный бонус/переход на
  следующую фазу, а не каждый день.
- Различать: временные сессии (роли по проекту) и постоянные «персонажи»

## 4. Ограничения (защита от искажений)

- Никаких очков «любви/преданности»; только измеримые рабочие результаты
  (легитимная механизмика, не имитация чувств).
- Метатокены даются за **подтверждённую экономию**, а не за «дешёвый/частичный»
  результат; анти-паттерн: экономить, ломая качество.
- XP/метатокены живут в append-only файле; продумать уязвимость:
  double counting/одна и та же задача в двух отчётах.
- Единая валюта не превращается в контроль мысльей; отвечает только за
  «покупку» инструментов/способностей, не за согласие с каноном.

## 5. Пример цикла (машина, не воскресенье)

1. Агент igraphv2 сессия «igraphv2» hello → постоянная роль.
2. Завершает граф-апдейт: verifier PASS + commit INCLUDED.
3. Метрики: подтверждение экономии (прогон частоты референсов против
   контрольного) + полный отчёт.
4. XP начислен; «дешёвая задача в чеке» — с этой iронии игрок мог бы
   «купить» лучший навык/утилиту при следующем мандате.
5. После н ReadOnly Hello: идём дальше.

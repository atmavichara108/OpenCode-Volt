# Квесты Корабля (механика v0)

**Зачем:** роадмапы, индексы и ветки расползлись — владелец теряется. Квесты
заменяют их: один взгляд на карту, понятный прогресс, связи видны.

**Ризомная архитектура (принцип):** квест не список, а **узел**: он связан
с другими квестами (предусловие → открывает → параллелен). Механика — по
ADR-032 (индекс + тип-имя) и нашей доктрине (S0-цена: карта не грузится
на старте).

## Носители
| Файл | Что | Кто ведёт |
|---|---|---|
| `quests.md` | реестр квестов: id, имя, статус, владелец, зависимость | ЦУ (реестродержатель) |
| `quests.canvas` | ризома: узлы=квесты, рёбра=зависимости | Служитель Обсидиан (UI/UX) |
| `quests-index.md` | триггеры: «чем заняться сейчас» | Служитель |
| `Q-NNN-<slug>.md` | тело квеста: цель, шаги, DoD, награда | исполнитель квеста |

## Формат квеста (frontmatter)
```yaml
id: Q-001
тип: квест
имя: "путь разработчика NVIDIA"
статус: active | locked | done | parked
владелец: ЦУ | ИЦ | Служитель | ИПТ | Лаба | владелец
предусловие: []
открывает: [Q-002, Q-003]
шаги: [...]
DoD: [...]     # что считается завершением
награда: [...] # что получаем (квоты, статус, артефакт)
```

## Правила
1. **Один квест — один файл.** Квест без DoD не открывается.
2. **Один активный квест на линию** (не плодим параллель).
3. **Квест не закрывается словами** — только evidence (как в приёмке).
4. **Грубо сейчас, красиво потом** — слова владельца 2026-10-23: механика
   работает сразу, эстетика (canvas-карта) приводится постепенно.

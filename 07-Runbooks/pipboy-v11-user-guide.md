# Pip-Boy v11 — Руководство оператора

> **Pip-Boy** — централизованный модульный мультиплексор экосистемы OpenCode-Vault, объединяющий управление проектами, терминалами, браузером, графом зависимостей, канбаном, состоянием агентов и переключением их моделей.

---

## 1. Запуск и интеграция

### Из консоли / CLI
```bash
# Поднять локальный HTTP-хост в фоне (порт 8123, auto-idle 30 мин)
python3 tools/ecosystem-map/pipboy.py up

# Поднять и сразу открыть в браузере (или по умолчанию)
python3 tools/ecosystem-map/pipboy.py open

# Проверить статус хоста
python3 tools/ecosystem-map/pipboy.py status

# Погасить хост
python3 tools/ecosystem-map/pipboy.py down
```

### Из Rofi (Launcher)
- Нажми свой горячий лаунчер и выбери `Pip-Boy`, либо запусти `pipboy-rofi`.
- Меню содержит быстрый доступ ко всем ключевым видам и управлениям хостом.

### Из OpenCode (команда `/agents`)
- Вызов `/agents` поднимает хост и открывает дашборд на вкладке **MODELS** (через deep-link `#models`).

## 2. Рабочие профили (Work Profiles)

В верхней панели доступен выпадающий список **Рабочий профиль**, мгновенно настраивающий видимые тайлы под текущую задачу:

1. **Overview** (`Overview`): `launcher`, `ecosystem`, `projects`, `health`, `next`, `kanban`, `matrix` — общий обзор состояния экосистемы и активного проекта.
2. **Build** (`Build`): `ecosystem`, `terminal`, `browser`, `upgrade`, `dependency`, `next` — контур разработки, тесты и сборка.
3. **Control** (`Control Plane`): `launcher`, `terminal`, `browser`, `acceptance`, `proposal`, `agent` — управление задачами, проверка evidence и агенты.
4. **Models** (`Models & Agents`): `models`, `skills`, `matrix`, `link` — дашборд переключения моделей всех 19 агентов и граф навыков.
5. **Capture** (`Capture / Intake`): `search`, `link`, `projects`, `proposal`, `acceptance` — поиск и обработка входящих артефактов.
6. **All** (`All`): все 18 тайлов (полный мультиплексор).

Состояние профиля, порядок и размеры тайлов сохраняются раздельно по проектам в `localStorage`.

## 3. Раскладки (Layout Presets)

Доступны 9 раскладок (переключаются кнопками в топбаре, по клавише `Alt+Shift+=` или через command palette):

- **Columns** (`▤`, дефолт): двухколоночный сбалансированный режим.
- **TreeTab** (`☷`): иерархический режим с выделенной левой панелью и свёрнутыми телами неактивных тайлов.
- **Plasma** (`✹`): динамическая адаптивная сетка (auto-fit).
- **Three Columns** (`▥` / `monad3`): центральный master-тайл + левая и правая утилитарные колонки.
- **Slice** (`◧`): постоянная узкая левая панель утилит + основная рабочая область.
- **Grid** (`⊞`): адаптивная таблица.
- **Focus** (`▣`): первый тайл на всю ширину сверху, остальные под ним.
- **Focus2** (`◨`): активный тайл развёрнут (62vh), остальные свёрнуты в аккуратные полоски-заголовки (клик по заголовку мгновенно переключает фокус).
- **Rows** (`≡`): вертикальный стек (удобно для чтения или мобильного экрана).

## 4. Управление моделью агентов (вкладка MODELS)

Вкладка **MODELS** показывает таблицу всех агентов системы (глобальные `.md`, проектные `.md` и встроенные в конфиги):

1. **Таблица**: имя агента, scope (`GLOBAL` / `PROJECT`), проект, тип, текущая модель.
2. **Селект**: выпадающий список всех доступных моделей (live из `opencode models`, declared, in-use, плюс псевдонимы из `providers.json`).
3. **Применение**: смена селекта автоматически отправляет запрос на бэкенд. model-router выполняет **точечную правку** строки `model:` во фронтматтере агента (без пересборки файлов) с `flock` и бэкапом в `.model-router-backups/`.
4. **Toast + Undo**: после успешной смены появляется тост с кнопкой `↩ отменить` (живет 9 секунд), позволяющий мгновенно откатить изменение назад в один клик.
5. **Важно**: смена модели правит конфигурационный файл. Изменение вступает в силу после **рестарта инструмента / новой сессии** (hot-reload моделей в движке OpenCode нет).

## 5. Безопасные горячие клавиши (Alt-контракт)

Чтобы не создавать конфликтов с оконным менеджером (qtile), tmux и горячими клавишами браузера, управление Pip-Boy вынесено на **Alt+Shift**:

| Комбинация | Действие |
|---|---|
| `Alt+Shift+H / J / K / L` | Фокус тайла влево / вниз / вверх / вправо |
| `Alt+Shift+Z` или `Alt+Shift+F` | Развернуть сфокусированный тайл на весь экран (fullscreen ⤢) / вернуть в сетку |
| `Alt+Shift+X` | Закрыть сфокусированный тайл |
| `Alt+Shift+P` | Открыть командную палитру (Command Palette) |
| `Alt+Shift+R` | Обновить все смонтированные модули |
| `Alt+Shift+N` | Сбросить/нормализовать соотношение размеров |
| `Alt+Shift+T` | Переключить тему (phosphor → amber → ice) |
| `Alt+Shift+C` | Переключить компактную плотность сетки |
| `Alt+Shift+[ / ]` | Изменить ratio раскладки |
| `Alt+Shift+=` | Следующая раскладка |
| `Alt+1..9` / `Alt+0` | Быстрое переключение проекта по номеру / ВСЕ проекты (ALL) |
| `?` | Справка по клавишам |
| `Esc` | Выход из фуллскрина, снятие фокуса или закрытие оверлея |

*Примечание*: внутри полей ввода, текстовых полей, селектов и встроенных терминалов клавиатурные сокращения Pip-Boy уступают место самому приложению.

## 6. Визуальный стиль и темы (Crypto-Cyber-Solarpunk)

Поддерживаются 3 темы (переключаются через `Alt+Shift+T`, палитру или кнопку `◐` в топбаре):

1. **Phosphor** (дефолт): классический зелёный терминальный оттенок на глубоком тёмном фоне.
2. **Amber**: тёплый янтарный киберпанк-стиль.
3. **Ice**: холодный крипто-синий high-tech стиль.

Все 57 полупрозрачных элементов интерфейса используют динамические RGB-переменные (`rgba(var(--rgb-*), alpha)`), поэтому смена темы полностью преображает весь дашборд, включая линии, подсветки и скроллбары.

## 7. Управление состоянием тайлов

- **Rail слева**: узкая панель навигации (можно развернуть кнопкой `«`/`»` в широкую до 168px). На мобильных устройствах rail автоматически превращается в удобную нижнюю панель.
- **Статус-точки и бейджи**: в шапке каждого тайла и на кнопках rail отображаются индикаторы (например, предупреждения о циклах, frozen-задачах или количестве доступных задач).
- **Lazy mount**: тайлы монтируются и запрашивают данные только тогда, когда попадают во вьюпорт (IntersectionObserver). Стартовая загрузка ALL-режима мгновенная.
- **Skeleton и Retry**: при загрузке тайла показывается анимированный шиммер, а в случае сетевой или программной ошибки — блок `✕ не загружено` с кнопкой `⟳ повторить`.

# Капитанский мостик (10-Deck)

Слой вывода: важные решения Корабля, **ждущие твоего слова** — в виде
интерактивных карточек Obsidian.

## Что здесь
- `decisions-deck.md` — карточки решений (frontmatter: id, тип, имя, статус,
  ведомство, вопрос, варианты, дедлайн)
- `deck.canvas` — ризома-карта: узлы = решения, рёбра = зависимости

## Откуда данные
Источник правды — реестры волта (decision-queue, session-log, route-log).
Deck — **проекция** (ssot: false), как Doctrine: реестры — истина, Deck —
представление. Служитель Обсидиан наполняет и поддерживает.

## Как читать
- Открой `decisions-deck.md` в Obsidian — карточки по порядку.
- Canvas-карта — `deck.canvas`: связи между решениями, зависимости.
- Статус «ждёт слово» — твоё решение требуется; «принято» — закрыто.

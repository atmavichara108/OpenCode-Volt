# Капитанский мостик (10-Deck)

Слой вывода: важные решения Корабля, **ждущие твоего слова**, и живой обзор
экосистемы. Канонизация содержимого — владелец; Deck — проекция (`ssot: false`).

## Почему не как раньше (v1–v3 → v4)

Владелец 2026-10-23 (basis: quoted): «не понравились макароны из канвасов,
очень многое чтобы точечно описывать… в таком виде как есть я не могу принять
дек. к тому же он устаревает и не обновляется динамически. нужно радикально
новый взгляд и эффективные решения».

Диагноз: canvas — холст для ручного мышления, а реестры меняются ежедневно.
Проекция реестров в 30+ статических файлов давала снимок, который устаревал
быстрее, чем пересобирался.

## Принцип v4: одна дверь, живые виды, ноль ручной поддержки

| Файл | Что | Роль |
|---|---|---|
| `deck.md` | единственная точка входа | обзор, тянет данные сам |
| `quests.base` | Obsidian Bases | живые таблицы: «Чем заняться сейчас», «Все квесты» |
| `DECK.canvas` | скелет | 3 узла-ссылки, только навигация |
| `decisions-deck.md` | карточки решений | ждут слова владельца |
| `_gen/quests_data.py` | генератор | создаёт/синхронизирует файлы квестов из реестра ЦУ |
| `_gen/deck_skeleton.py` | генератор | пересборка скелета |

**Правило:** руками в представление не пишем. Меняется реестр → меняется вид.
Генератор трогает только управляемые поля (статус/владелец/предусловие/
открывает), тело квеста и DoD ведёт исполнитель.

## Источники правды (не Deck)

- манифесты/отсеки — `04-Memory/peer-registry.md`, реестр манифестов УАС

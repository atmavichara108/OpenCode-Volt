# Капитанский мостик (10-Deck)

Слой вывода: важные решения Корабля, **ждущие твоего слова** — карточки;
плюс полная визуализация экосистемы вложенными canvas (слово владельца
2026-10-22: «полную визуализацию экосистемы используя канвасы с вложенными
канвасами для отображения разных уровней»).

## Что здесь
- `decisions-deck.md` — карточки решений (frontmatter + источники файл:строка)
- `deck.canvas` — ризома решений (карточка = узел, зависимость = ребро)
- `map-L0-ship.canvas` — **Корабль** (галактика): грани-проекты, мостик
- `map-L1-<грань>.canvas` — **грани = проекты** (vault, dotfiles, dv-hub, SSA, …)
- `map-L2-<ведомство>.canvas` — **ведомства**: грани — подведомства, навыки,
  журналы, агенты
- `map-L3-<ведомство>.canvas` — **артефакты-производные**: пути, роадмапы, спеки
- `_gen/deck_levels.py` — генератор карт (пересборка:
  `python3 10-Deck/_gen/deck_levels.py` из корня волта)

Точная вложенность: узел типа file с .canvas рендерится Obsidian'ом как
вложенная карта — L0 открывает L1, тот L2, тот L3.

## Откуда данные
Источник правды — реестры волта (peer-registry, decisions-registry,
session-log, 03-Projects). Deck — **проекция** (ssot: false). Служитель
Обсидиан наполняет и поддерживает; ничего не выдумывается — только то,
у чего есть файл:строка.

## Как читать
- `decisions-deck.md` — карточки; «ждёт слово» — нужно твоё решение.
- `map-L0-ship.canvas` — точка входа в экосистему, дальше проваливай вниз.

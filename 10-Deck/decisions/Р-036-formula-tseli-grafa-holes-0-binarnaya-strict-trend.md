# Р-036 — Формула цели графа: holes→0 (бинарная) + strict-тренд + adjusted резерв; знаменатель не чистим.** Контекст (математика Лабы, независимая приёмка): при знаменателе 834 потолок strict-покрытия после закрытия всех дыр = 78.4%; цель «strict ≥90» при таком знаменателе недостижима в принципе — это формула, не темп

## Статус
действует; владельцу — в отчёт

## Суть решения
Варианты: (а) чистый знаменатель (минус 180 легитимных → 654) — ОТВЕРГНУТ (манипуляция знаменателем = ADR-класс «красивое число», anti-goodhart); (б) бинарная цель holes→0 + строгий тренд; (в) movement без численной цели. Вердикт ЦУ (критерий передан Лабой ЦУ; рекомендация Лабы = (б)+(в)): **(б)+(в) вместе** — главная цель бинарная «реальных дыр → 0» (конечный worklist, не подкручивается), strict-число публикуется как тренд без численной цели, adjusted — резерв. Обоснование каноном: «пороги, не ярлыки» + Гейт 7 + урок роадмапа о подгоне цифр.

# Р-108 — Секреты и токены: только минимальные права с объяснением; широкий classic-токен для автоматики запрещён.** Слово владельца (basis: quoted, через линию ДВ-хаба, 06.11)

## Статус
действует

## Суть решения
Канон: (1) любой секрет/токен — минимально необходимые права (объём назван), объяснение зачем и куда уходит, срок жизни; (2) классический токен с правами на все репозитории для автоматики запрещён — только точечный доступ (например, запись содержимого одного репозитория + чтение метаданных); (3) инструкция владельцу по секрету даётся командами и кликами (Р-106) и не содержит самого секрета; значение проходит Ворота секретов (~/.secrets), не перепиской; (4) приёмка — строка правок токена и проверка, что объём не расширен. Первое применение: CI dv-project переведён с классического на точечный токен, прежняя инструкция отозвана.

# Р-047 — Канонический путь агентского слоя объявлен: .opencode = SOT, .mcode = зеркало движка.** Основание: первопричина инцидента ConfigInvalidError (06-Audits/2026-10-31-mcode-cary-race.md, root cause по mcode.log:8126): M Code при старте сам переносит конфиг .opencode→.mcode и грузит сессии в том же окне — гонка ~1.7с (226× load-failed, одноразово)

## Статус
действует

## Суть решения
Канон: .opencode — единственный трекаемый источник агентов/комманд/скиллов; .mcode — рабочее зеркало (carry при старте; руками не правим, .opencode не удаляем). Миграция-стэш с удалениями трекаемых .opencode объявляется НЕ-каноном: удаления не коммитим, востановленные копии остаются. Fix-3 — дефект гонки разработчику через beta-канал (мандат mcode-tg): черновик → апрув владельца → send.

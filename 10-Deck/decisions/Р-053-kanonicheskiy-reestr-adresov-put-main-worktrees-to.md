# Р-053 — Канонический реестр адресов — путь main; worktrees — только для выкладки сессий.** Симптом (находка ОШ, 02:1x): `ship-mail` не отправил — registry not readable: peer-registry.md отсутствовал на каноническом пути; причина — не миграция .mcode, а checkout ветки в ОБЩЕМ дереве волета параллельной сессией (файл есть в репозитории, но не в той ветке)

## Статус
действует

## Суть решения
Канон: (1) канонический источник реестра — 04-Memory/peer-registry.md в origin/main, переезда нет; (2) параллельные сессии выкладываются в worktrees ( OpenCode-Vault-tasks/*), checkout в общем дереве — только через tree-cop, иначе дефект «файлы исчезают у соседей»; (3) дубли реестра вне main не создаются; аварийный обход (SHIP_MAIL_REGISTRY) — read-only fallback, не источник. Мандат ИЦ: поиск реестра по путям + явная ошибка «РЕЕСТР НЕ НАЙДЕН» вместо недоставки.

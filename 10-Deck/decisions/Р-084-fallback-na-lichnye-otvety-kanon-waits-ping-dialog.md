# Р-084 — Fallback на личные ответы: канон = waits+пинг; диалоговая реализация допускается с тремя дополнениями.** Слово владельца (basis: quoted, через Смотрителя HR): если человек написал в личку и владелец не ответил в течение часа — отвечает Офис по подтверждённым условиям

## Статус
действует

## Суть решения
Канон: механизм штатный (реестр ожиданий, тип question + return_condition + deadline 60м + каденс-пинг + «опоздание — вердикт, если названо»); диалоговая реализация (файл проекта) допускается с дополнениями: (1) запись-ожидание на каждое ожидаемое личное; (2) на истечении — пинг + переход к назначенному ответчику с журналом «кто ответил» (актор owner/fallback); (3) журнал append-only, совместим с реестром отправителей. Красная линия: fallback не заменяет владельца в обязательствах/деньгах/апрува; отдельные диалоги (напр. работодатель) — без fallback, эскалация.

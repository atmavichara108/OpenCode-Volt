# Р-072 — Genspark: зонды — только с отдельного аккаунта; платная подписка владельца исключена.** Слово владельца (basis: quoted, из капитанского портала через AllIs Maya): «Да на все рекомендации

## Статус
действует

## Суть решения
А генспарк булем зондировать с другого акка, не с моей платной подписки чтобы не рисковать». Канон: (1) зонды Genspark ведутся только с отдельного аккаунта; (2) аккаунт владельца с платной подпиской — исключён из любой автоматизации; (3) это разрешение на ЗОНДЫ, не на ротацию — ротация только отдельным словом владельца; (4) доступы/секреты отдельного аккаунта — через Ворота, вне репо и журналов; (5) без пошаговой валидации аккаунта (существование → активность → лимиты) — не зондировать; (6) создание стороннего аккаунта — только слово владельца (вопрос в портале: создаёт сам или поручает).

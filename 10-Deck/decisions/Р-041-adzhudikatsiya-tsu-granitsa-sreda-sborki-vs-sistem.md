## Суть решения
Вердикт: каноны не конфликтуют — у них разная область. Зона ведомства (ИЦ, операционное исполнение по git-silence 10-30): локальная сборка в каталоге — клон, fnm install (Node 22.12.0), uv (Python 3.12.13), venv, pip-зависимости, запуск на 127.0.0.1. Собранное ИЦ окружение (бэкенд 127.0.0.1:8765, docs 200, health ok) канону соответствует и не аннулируется; следующий шаг ИЦ не блокирован, пока не выходит из каталога сборки.

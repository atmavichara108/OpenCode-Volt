# Р-045 — Граница ЦСПиМ — сквозной вердикт (после вводных УАС).** Зоны: ЦСПиМ (SCRUM-master) принимает на баланс канву planning-слоя (сводная карта роадмапов/тасков/квестов/инбоксов), контроль WIP=1 (Р-039), конфликт-рапорты приоритетов, методологию (Scrum/Kanban/Lean/Кайдзен) — консультационно на любой уровень

## Статус
действует

## Суть решения
Остаётся у ведомств: свои SSOT-реестры и их ведение (ЦСПиМ ведёт карту и свежесть, не переписывает). Остаётся у ЦУ: оперативная координация, реестр адресов, канонизация через владельца, арбитраж. Остаётся у ИЦ: код инструментов планирования (goal, waits, отчётчики, каталог канвы) — ЦСПиМ пользуется, ИЦ чинит. 7 находок инвентаризации разведены по владельцам (стык наявки-7: инструмент — ИЦ, эксплуатация — SCRUM-master). Методологическое ядро обязательно имеет машинные «спарки» (спринт→цель-объект, канбан→очередь с TTL, инкремент→приёмка verifier, потери→freshness-сигналы, кайдзен→урок в память) — иначе метод = декор (тест Р-024). Пилот Р-044 согласован: оформление репо почтового хаба (участники Apps-dev + ИЦ + ЦУ).

# Пайплайн сбора карточек (для Служителя)

Источники (read-only, в порядке приоритета):
1. `control-plane/decision-queue/cards/` — pending/acceptance карточки (это живые дилеммы)
2. `04-Memory/session-log/` — блоки «ждёт слова владельца» / «Жду ответ»
3. Письма-мандаты без ответа (receipts без ack >48ч)
4. `control-plane/route-log` — решения, упомянутые в маршрутах

Правила:
- Карточка = одно решение (один вопрос к владельцу)
- id — уникальный (по message_id или тема+дата)
- Имя — из слов владельца (ADR-032: имя из его формулировки)
- Статус «ждёт слово» → после ответа → «принято»/«отменено»
- Дедлайн: если не задан — +7 дней от создания карточки
- Canvas: рёбра — только реально существующие зависимости (не выдумывать)
- Deck — ssot:false: не удалять строки реестров, только проекция

## 3. Внешние находки (класс → что переносим)

1. **Интерактивные локальные графы** — Juggl (интерактивный стилизуемый граф,
   workspace-режим, API расширения), ExcaliBrain (TheBrain-подобная навигация
   по бэклинкам с breadcrumb-историей посещений). Берём: breadcrumb-тропу
   навигации + боковую панель соседей узла в тайле GRAPH.
2. **Memory-графы агентов** — Zep/Graphiti (temporal knowledge graph: факты
   меняются во времени, bi-temporal edges), Cognee, Mem0, Letta (сравнительные
   бенчмарки 2026). Берём идею **временных рёбер** для idea-graph (факт имеет
   интервал жизни) и визуализацию «память дышит» — не внедряем чужие бэкенды,
   наша память остаётся файловой (Memory over claude-mem — VibeOS.md).
3. **Пространственные UI** — Kinopio/Heptabase (пространственное мышление,
   бесконечный холст с группировками), Gather/WorkAdventure (комнаты-отсеки
   как топология присутствия). Берём паттерн: отсек = узел-комната с
   присутствием сессий (peer-registry как схема комнат, route-log как лог
   перемещений).

## 4. Маппинг на терминал 1.0 (пип-бой v11 + deck)

- Тайл **DECK**: встраиваемые карты L0→L3 (canvas-in-canvas уже рендерится
  Obsidian'ом; в Пип-Бое — те же JSON-канвасы через file-ноды/iframe).
- Тайл **GRAPH**: idea-graph + ходьба по викилинкам, поиск по словам (mem-index),
  breadcrumb-тропа (ExcaliBrain-паттерн).
- Тайл **ROOMS**: отсеки-ведомства (peer-registry), события (route-log),
  присутствие сессий.
- Тайл **SKILLS**: ризома навыков (skill-taxonomy, tsu-*, панели команд).
- Редактирование в моменте: канвас-узел → файл (у нас уже так: узлы file-типа),
  двусторонняя связь канвас↔файл — «управление средой через файлы».
- Управление: Alt-контракт v11 сохраняем; новые тайлы = конкретизация
  существующих (work profiles/layouts переиспользуем).

## 6. Риски

- Внешние инструменты — источники идей, не зависимостей: память остаётся
  файловой и версионируемой (анти-goal — внешние memory-сервисы).
- Вложенные canvas в Obsidian тяжеловесны при больших картах — генератор
  держит карты компактными; в Пип-Бое рендерим лениво (lazy mount уже есть).

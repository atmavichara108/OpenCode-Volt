# P-1. Оценка community-плагина до установки

## Зачем

Плагин — это код, исполняемый внутри волта с доступом к заметкам (а через
 них — к реестрам Корабля). Установка «по хайпу» = чужой код у источника
правды. Протокол делает оценку повторяемой: один и тот же чек-лист для
любого кандидата, в любом клиенте Служителя (волт, будущие SerO-проекты).

## Гейт-лист (8 пунктов; провал любого из G1–G3 = отказ без обсуждения)

| # | Критерий | Что проверяю | Порог |
|---|----------|--------------|-------|
| G1 | Local-first / приватность | сеть, телеметрия, облако; если есть — отключаемо? | без моего ведома данные наружу не идут |
| G2 | Лицензия | MIT/Apache/BSD/ISC | проприетарная/неясная — отказ |
| G3 | Безопасность кода | eval/remote code, запрос секретов, записи вне волта | любой красный флаг — отказ |
| G4 | Живость поддержки | последний релиз, открытые критические баги, реакции автора | релиз ≤ 12 мес; мёртвый — только если код тривиален |
| G5 | Совместимость | Bases, Canvas, свойства, наш текущий сет | конфликт с ядром — отказ |
| G6 | Вес и зависимости | размер, число npm-зависимостей, скорость старта волта | заметно тормозит старт — вниз очереди |
| G7 | Зрелость | загрузки, issues/PR культура, документация | «hobby-эксперимент» — только в песочницу |
| G8 | Версионирование | pinned-версия в community-plugins.json + запись в реестре | без пина не ставится |

## Процедура (4 шага)

1. **Кандидат** — из нужды (задача владельца/ЦУ), не «на посмотреть».
   Источник: официальный community-catalog или репозиторий автора.
2. **Чек-лист G1–G8** — по README/кодом/релизам; вердикт предварительный.
3. **Песочница** — установка в копию волта (не в живой), прогон на своих
   данных-двойниках; поведение при отключении (чисто ли убирается).
4. **Вердикт и запись** — принят (с пином версии) / отклонён (причина в
   реестре). Для Корабля: установка в волт — после верификации ИЦ;
   для SerO-проектов — вердикт Служителя, запись в реестр проекта.

## Эталон (уже прошедшие P-1 до его формализации)

Сокровищница TradingMind: copilot, dataview, obsidian-git,
smart-connections, templater — ретроспективно прогнать по G1–G8,
расхождения записать, а не молча принять.

## Реестр плагинов

`10-Deck/plugins-registry.md` (создам при первом принятом): имя, версия
(пин), дата, вердикт, гейты с пометками, где стоит (волт/проект), кто
утвердил. Реестр — источник правды; Deck-проекции — ssot:false.

## Границы

- Секреты в заметках — запрещены каноном; плагин, вынуждающий хранить
  токен в заметке, не проходит G3 независимо от полезности.
- Плагин нужен, но не проходит гейт — не обход: ищу альтернативу или
  ставим задачу obsidian-plugin-dev (P-2) на свой аналог.

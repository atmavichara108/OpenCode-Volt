# P-4. Гейт приёмки этапа

## Когда применяется

Каждый этап и каждая волна рубки — A целиком, любой подэтап A (например
«модуль решений»), волны B и C. Один гейт для всего — разная только
ширина проверок (риск-соразмерность): подэтап модуля — уже, весь этап A —
полная пачка.

## Пять ступеней, порядок неизменен

| # | Ступень | Кто | Что фиксируется |
|---|---|---|---|
| G1 | Самопроверка исполнителя | Служитель | чек-лист этапа прогнан на своих данных; smoke реальным запуском (не «синтаксис ок») |
| G2 | Независимая верификация | verifier/ИЦ | PASS по тому же hash/состоянию, что и G1; real run |
| G3 | Живой рендер владельцем | **владелец** | «да» своими глазами в живой среде — единственный вход, слово владельца |
| G4 | Ship-порядок | ЦУ | сигнал merge/выкладки; без него в main не идём |
| G5 | Фиксация | Служитель | рапорт ЦУ: hash коммита, вердикты, дата, кто принимал; запись в досье/реестр решений |

## Жёсткие правила

1. **Провал любой ступени = возврат на доработку.** Не «примем с
   оговоркой», не «починим в следующей волне» — следующий прогон гейта
   с начала (G1), если менялось что-то, влияющее на проверенное.
2. **Мутирующая правка аннулирует вердикты.** Любое изменение кода/конфига
   после G2 — гейт заново (минимум G1+G2; после G4 — тоже, потому что
   проверялось другое состояние).
3. **G3 не делегируется.** Ни ЦУ, ни ИЦ не дают «да» вместо владельца;
   их согласие — необходимое, но не достаточное.
4. **Merge до G3+G4 запрещён** независимо от готовности кода (дейли
   ветка ждёт, никто не торопится).
5. **Провал на живом рендере (G3)** → откат по ship-порядку ЦУ + запись
   инцидента (symptom → repro → root cause → fix → evidence) — не тихий
   revert.

## Evidence-минимум для G5

- hash коммита(ов) этапа;
- вердикты: G1 чек-лист, G2 PASS/FAIL с именем верификатора, G3 слово
  владельца (дата), G4 сигнал ЦУ (id письма);
- известные ограничения и открытые вопросы — списком, не молчанием.

## Приложение: чек-лист этапа A (условия из досье, ч.4)

- [ ] авто-живость: приборы обновляются по событиям, метка времени на экране;
- [ ] кнопки решений работают только через Ворота (P-3 §3);
- [ ] 7 приборов читают источники из P-3 §2, серое состояние честное;
- [ ] kill-switch каждого модуля работает, авария прибора не роняет рубку;
- [ ] Обсидиан не пострадал: Deck живёт, канон не тронут (Обсидиан = канон
  и архив — условие варианта A);
- [ ] откат: одна команда возвращает волт/Пип-Бой в состояние до этапа.

## Что из этого следует для P-1 (не молча, кандидатами)

1. **AGPL-3.0** у templator/copilot — вне текущего allowlist P-1
   (MIT/Apache/BSD/ISC). Для *использования* плагина в своём вольте AGPL
   не запрещает ничего; ограничения бьют по форкам и распространению.
   Кандидат в P-1: строка «copyleft (AGPL/GPL) — разрешено для
   использования, запрещены форк-и-шип без слова владельца». Твоё слово.
2. **G1 Needs refinement**: «облачный API по умолчанию» — не отказ, но
   условие «в Корабле — только с явно настроенным локальным/своим
   эндпоинтом, облачные ключи в заметках запрещены». Кандидат.
3. G4 у dataview показывает границу (~11 мес) — протокол отработал честно.

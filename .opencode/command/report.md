Команда: /report $ARGUMENTS

Без аргумента — все линии.

## Жёсткие правила
- **Слово владельца — единственная авторизация;** `basis: quoted`, домыслы
  запрещены; неоднозначность → вопрос, не трактовка.
- **`general` не является silent fallback;** неизвестный маршрут = `UNROUTABLE`.
- Ссылки: [[02-Methods/capability-routing]], [[04-Memory/peer-registry]],
  [[01-Policies/skill-taxonomy]], [[02-Methods/ministry-calibration]],
  [[01-Policies/decisions-registry]].

## Шаги

1. **Источники:** `TASKS.md`, [[04-Memory/active-context]], последний
   session-log, [[04-Memory/peer-registry]], входящие/исходящие письма,
   route-log.

2. **Группировка:**
   - (а) работает сейчас;
   - (б) ждёт слова владельца — каждое одной строкой с прямым вопросом;
   - (в) блокеры/инциденты;
   - (г) закрыто с evidence за период (путь/коммит/вердикт, не «сделано»).

3. **Простой человеческий язык:** без кода, без диффов, без пересказа одних
   и тех же файлов; объём — один экран.

4. **Не принимать решений за владельца.** Спорное — вопрос с вариантами,
   без выбранной «по умолчанию» трактовки.

5. **Дайджест дописать в session-log** (append-only, без правки прошлых
   записей).

## Выход
Доклад по группам (а)–(г) + путь записи в session-log.

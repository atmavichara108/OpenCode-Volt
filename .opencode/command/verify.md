Команда: /verify $ARGUMENTS

Запусти детерминированную проверку волта:

```bash
python3 tools/verify-cache/verify.py $ARGUMENTS
```

- Без аргументов — использует tree-hash кэш (повторный прогон на неизменённом
  дереве не пересчитывает проверки).
- `--force` — игнорировать кэш, пересчитать все гейты.
- `--json` — машинный вывод (для передачи другому агенту/верификатору).

## Что проверяется
1. Пустые `.md`-файлы в контент-слоях волта.
2. Битые викилинки (цель не резолвится в файл; литеры в code-span
   и anchor-ссылки `#...` игнорируются).

## Как ответить
- `exit 0` — все гейты прошли: сообщи «✅ verify: tree <hash> — гейты зелёные».
- `exit 1` — есть проблемы: перечисли найденные пустые файлы / битые ссылки
  и предложи фикс (не правь сам без подтверждения, если это контент-решение).
- `exit 2` — ошибка ввода: сообщи текст ошибки.

Кэш живёт в `tools/verify-cache/generated/verify-cache.json` (gitignored) —
не коммитить. Источник правды гейтов — сам скрипт `verify.py` (stdlib).

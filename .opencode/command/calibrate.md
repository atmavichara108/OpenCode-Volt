Команда: /calibrate $ARGUMENTS

Аргумент — `ведомство` или `all`.

## Жёсткие правила
- **Слово владельца — единственная авторизация;** `basis: quoted`, домыслы
  запрещены; неоднозначность → вопрос, не трактовка.
- **`general` не является silent fallback;** неизвестный маршрут = `UNROUTABLE`.
- Ссылки: [[02-Methods/capability-routing]], [[04-Memory/peer-registry]],
  [[01-Policies/skill-taxonomy]], [[02-Methods/ministry-calibration]],
  [[01-Policies/decisions-registry]].

## Шаги

1. **Прочитай** [[02-Methods/ministry-calibration]] и карточку/строку реестра
   ведомства (оргструктура, [[04-Memory/peer-registry]]). Выбери вариант:
   **A** (новое ведомство с нуля) / **B** (новый отдел при существующем) /
   **C** (портирование существующего). Вариант не угадывается — при
   неоднозначности вопрос владельцу.

2. **Прогони 6 шагов с evidence:**
   1. repo-корень;
   2. письменный пакет конвенций (подпись обеих сторон);
   3. канал: полный sessionID, liveness, письмо туда-обратно +
      delivery-check;
   4. память;
   5. реестры (оргструктура, карточка проекта, peer-registry);
   6. смоук нейтральным мандатом.

3. **Отсутствие любого шага = «не откалибровано».** Боевые мандаты такому
   адресу не отправляются (→ `UNROUTABLE`).

4. **`all`** — только шаг «канал» для всех адресов реестра: liveness +
   сверка полных id; рассылка калибровочных писем без нужды запрещена.

5. **Результат:** таблица 6 строк с evidence + что осталось незакрытым.
   Калибровка без evidence не считается выполненной.

## Выход
Таблица 6 шагов (шаг / статус / evidence) + список оставшегося.

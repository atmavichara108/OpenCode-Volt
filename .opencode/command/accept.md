Аргумент — ref: scope / ветка / коммит / файл артефакта / письмо.

## Жёсткие правила
- **Слово владельца — единственная авторизация;** `basis: quoted`, домыслы
  запрещены; неоднозначность → вопрос, не трактовка.
- **`general` не является silent fallback;** неизвестный маршрут = `UNROUTABLE`.
- Ссылки: [[02-Methods/capability-routing]], [[04-Memory/peer-registry]],
  [[01-Policies/skill-taxonomy]], [[02-Methods/ministry-calibration]],
  [[01-Policies/decisions-registry]].

## Шаги

1. **Собери пакет:** письмо ведомства, ветка/коммит, артефакт, заявленный DoD.
   Неполный пакет → вопрос отправителю, не догадка.

2. **Факт-сверка ТОЛЬКО по диску** (`git show`, файлы, журналы), не по словам
   отчёта. Самодекларация агента — **не evidence**.

3. **Независимый verifier:** `task(agent=verifier)` с DoD и точным
   hash/коммитом. Для mutable work verifier **обязателен**.

4. **Вердикт:**
   - `PASS` → merge/фиксация по канону волта, строка реестра
     (research-registry / карточка проекта), запись в память.
   - `FAIL` → мотивированный возврат ведомству с конкретными пунктами.

5. **Любая мутация после verdict аннулирует его** — новый gate, новый hash,
   повторный verifier.

## Выход
Вердикт, evidence-строки (пути/коммиты), коммит/merge, где именно записано.
